Ⅰ. 정보융합 문제 발견과 탐구 설계

[12정융01-01]
자신의 진로와 관심 분야에서 정보과학을 활용하여 해결할 수 있는 융합적 문제를 발견하고 탐구 주제를 선정한다.
  1. 진로·관심 분야와 관련된 문제 탐색
  2. 정보과학으로 해결 가능한 문제의 발견
  3. 탐구 가치와 실현 가능성 분석
  4. 구체적이고 명확한 융합 탐구 주제 선정
[12정융01-02]
선정한 문제의 원인, 조건, 입력과 출력, 제약 사항 등을 분석하여 해결해야 할 문제를 구조화한다.
  1. 문제 상황과 원인 분석
  2. 문제의 입력·출력 요소 파악
  3. 문제 해결의 조건과 제약 사항 분석
  4. 문제의 논리적 구조화 및 표현
[12정융01-03]
문제와 관련된 다양한 학문 분야의 자료를 탐색하고 정보과학의 개념 및 원리와 연결하여 융합적으로 분석한다.
  1. 다양한 분야의 신뢰성 있는 자료 탐색
  2. 자료의 적절성과 신뢰성 판단
  3. 정보과학 개념과 다른 학문 분야의 연계
  4. 자료를 활용한 융합적 문제 분석
[12정융01-04]
문제 해결을 위한 탐구 목표를 설정하고 수행 절차, 방법, 역할 및 일정을 포함한 탐구 계획을 설계한다.
  1. 구체적인 탐구 목표 설정
  2. 탐구 방법과 수행 절차 설계
  3. 역할·일정·자원 활용 계획 수립
  4. 실행 가능성을 고려한 탐구계획서 작성

Ⅱ. 데이터·인공지능 융합 탐구

[12정융02-01]
탐구 문제 해결에 필요한 데이터를 선정하고 적절한 방법으로 수집하여 분석 가능한 형태로 구성한다.
  1. 문제 해결에 필요한 데이터 정의
  2. 적절한 데이터 수집 방법 선정
  3. 데이터 수집 및 체계적인 저장
  4. 분석 가능한 데이터 구조로 구성
[12정융02-02]
수집한 데이터의 결측값, 이상값, 중복값 등을 처리하고 탐구 목적에 적합하도록 데이터를 전처리한다.
  1. 데이터 품질과 특성 분석
  2. 결측값·이상값·중복값 탐색
  3. 적절한 데이터 전처리 방법 적용
  4. 전처리 결과의 적절성 검증
[12정융02-03]
데이터를 분석·시각화하고 필요한 경우 인공지능 모델을 적용하여 문제와 관련된 의미 있는 패턴과 결과를 도출한다.
  1. 탐구 목적에 적합한 분석 방법 선정
  2. 데이터 분석 및 시각화
  3. 적절한 인공지능 모델의 선택·적용
  4. 분석 결과와 패턴의 해석
[12정융02-04]
데이터와 인공지능 활용 과정에서 발생할 수 있는 편향, 개인정보, 저작권, 공정성 등의 윤리적 문제를 분석하고 책임 있는 활용 방안을 제안한다.
  1. 개인정보 및 데이터 보호 문제 분석
  2. 데이터·AI 편향과 공정성 분석
  3. 저작권·출처 및 생성형 AI 활용 윤리 준수
  4. 책임 있는 데이터·인공지능 활용 방안 제안

Ⅲ. 소프트웨어 융합 문제 해결

[12정융03-01]
융합 문제를 해결하기 위하여 문제를 작은 단위로 분해하고 추상화하여 컴퓨팅 시스템으로 해결 가능한 형태로 표현한다.
  1. 복잡한 문제의 부분 문제 분해
  2. 문제의 핵심 요소 추출 및 추상화
  3. 부분 문제 사이의 관계 분석
  4. 컴퓨팅 시스템으로 해결 가능한 문제 구조 설계
[12정융03-02]
문제의 특성을 분석하여 적절한 자료구조와 알고리즘을 선택하고 효율적인 문제 해결 절차를 설계한다.
  1. 문제 특성과 요구 조건 분석
  2. 적절한 자료구조 선택
  3. 문제에 적합한 알고리즘 설계
  4. 알고리즘의 효율성과 타당성 분석
[12정융03-03]
프로그래밍 언어, 라이브러리, 오픈소스 및 다양한 디지털 도구를 활용하여 문제 해결 프로그램을 구현한다.
  1. 문제 해결에 적합한 프로그래밍 도구 선정
  2. 알고리즘을 기반으로 한 프로그램 작성
  3. 라이브러리·오픈소스의 적절한 활용
  4. 기능이 통합된 문제 해결 프로그램 구현
[12정융03-04]
구현한 프로그램을 다양한 조건에서 테스트하고 오류를 분석·수정하여 프로그램의 정확성과 효율성을 개선한다.
  1. 다양한 테스트 사례 설계
  2. 프로그램 실행 결과 검증
  3. 오류의 원인 분석 및 디버깅
  4. 프로그램의 정확성·효율성 개선

Ⅳ. 정보융합 프로젝트와 공유

[12정융04-01]
실생활 또는 자신의 진로 분야와 관련된 정보융합 프로젝트를 계획하고 협력적으로 수행하여 문제 해결 산출물을 개발한다.
  1. 프로젝트 목표와 요구사항 설정
  2. 프로젝트 수행 계획 및 역할 분담
  3. 협력적 프로젝트 수행
  4. 정보융합 산출물 개발
[12정융04-02]
프로젝트 수행 과정에서 산출물을 반복적으로 테스트하고 데이터를 근거로 문제점을 분석하여 해결 방안을 개선한다.
  1. 산출물의 기능 및 성능 테스트
  2. 테스트 결과와 데이터 수집
  3. 문제점과 개선 요소 분석
  4. 분석 결과를 반영한 산출물 개선
[12정융04-03]
프로젝트의 문제 해결 과정과 결과를 평가하고 정보기술의 사회적 영향과 윤리적 책임을 고려하여 탐구 결과의 가치를 판단한다.
  1. 프로젝트 수행 과정의 체계적 평가
  2. 문제 해결 결과와 목표 달성도 평가
  3. 사회적·윤리적 영향 분석
  4. 탐구 결과의 가치와 한계에 대한 성찰
[12정융04-04]
정보융합 탐구의 과정과 결과를 보고서, 발표, 시연 등의 다양한 형태로 표현하고 공유하며 피드백을 반영하여 발전시킨다.
  1. 탐구 과정과 결과의 체계적인 정리
  2. 탐구보고서 및 발표 자료 작성
  3. 프로그램·산출물의 효과적인 발표 및 시연
  4. 피드백을 반영한 결과 수정·보완 및 공유
