2. 학습 시작 멘트

자연 속 반복되는 구조와 재귀

눈송이를 확대하면 작은 가지가 보이고, 그 가지를 다시 확대하면 비슷한 모양이 반복됩니다. 양치식물의 잎, 나뭇가지의 갈라짐, 해안선의 굴곡도 큰 구조 안에 작은 구조가 되풀이되는 모습을 보입니다. 수학에서는 이를 자기 유사성이라고 설명하고, 공학에서는 복잡한 구조를 같은 원리의 작은 단위로 나누어 설계합니다.

생명과학에서 세포는 분열하여 더 작은 단위의 생명 활동을 이어 가고, 천문학에서는 은하 속에 별의 집단이 있으며 그 안에 다시 행성계가 존재합니다. 물리학에서는 복잡한 운동을 여러 단계의 더 작은 변화로 나누어 해석합니다.

재귀 함수도 이와 같습니다. 큰 문제를 같은 형태의 더 작은 문제로 바꾸고, 더 이상 나눌 필요가 없는 가장 작은 문제에 도달하면 답을 되돌려 줍니다. 오늘 우리는 반복되는 명령을 쓰는 것을 넘어, 문제 안에 숨어 있는 자기 닮은 구조를 찾아 코드로 표현합니다.

4. 개념 및 상세 설명 · 관련 코드 · 코드별 확인 문제

개념 1. 재귀 함수의 정의

재귀 함수는 함수가 자기 자신을 다시 호출하는 함수이다. 재귀는 큰 문제를 같은 형태의 더 작은 문제로 바꾸는 관계가 있을 때 유용하다.

아래 함수는 n을 출력한 뒤 n-1을 인수로 자기 자신을 호출한다. 매 호출마다 문제의 크기 n이 1씩 줄어든다.

자기 호출문제 크기 감소
def countdown(n): if n == 0: return print(n) countdown(n - 1) countdown(3)

출력: 3 → 2 → 1

코드 1 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ⑤
n이 0이면 return으로 종료하며, 출력 후 n-1을 호출하므로 3, 2, 1 순서로 출력된다.
개념 2. 종료 조건과 재귀 단계

재귀 함수에는 반드시 종료 조건이 있어야 한다. 종료 조건은 더 이상 같은 문제를 작게 나누지 않고 바로 답을 반환하는 가장 작은 문제이다.

종료 조건이 없거나 도달할 수 없으면 함수 호출이 계속되어 재귀 깊이 한계를 넘고 오류가 발생한다.

def print_stars(n): if n <= 0: return print("*" * n) print_stars(n - 1) print_stars(3)

코드 2 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ④
n이 0 이하이면 출력하지 않고 즉시 종료한다. 따라서 별 3개, 2개, 1개가 출력된다.
개념 3. 호출과 복귀 순서

재귀 함수가 호출될 때마다 각 호출의 매개변수와 실행 위치가 별도로 저장된다. 가장 나중에 호출된 함수가 먼저 끝나고 이전 호출로 복귀한다.

재귀 호출 앞에 있는 명령은 내려가는 과정에서 실행되고, 재귀 호출 뒤에 있는 명령은 돌아오는 과정에서 실행된다.

def trace(n): if n == 0: return print("호출", n) trace(n - 1) print("복귀", n) trace(3)

코드 3 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ③, ⑤
호출은 3→2→1로 깊어지고, 종료 조건에 도달한 뒤 복귀는 1→2→3 순서로 진행된다.
개념 4. 반환값을 이용한 재귀 합

재귀 함수는 복귀 과정에서 각 단계의 값을 결합할 수 있다. sum_to(n)은 n과 sum_to(n-1)의 결과를 더한다.

종료 조건 n == 0에서 0을 반환한 뒤, 이전 호출들이 차례로 1, 3, 6, 10을 만들어 낸다.

def sum_to(n): if n == 0: return 0 return n + sum_to(n - 1) print(sum_to(4))

코드 4 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ④
4+3+2+1+0이 되어 10을 반환한다. 곱이 아니라 합을 계산한다.
개념 5. 팩토리얼과 단일 호출 재귀

팩토리얼은 n! = n × (n-1)!이라는 재귀 관계를 가진다. 0!과 1!은 1이므로 이를 종료 조건으로 사용한다.

함수 안에서 자기 자신을 한 번만 호출하므로 단일 호출 재귀이다.

def factorial(n): if n <= 1: return 1 return n * factorial(n - 1) print(factorial(5))

코드 5 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ⑤
5!은 5×4×3×2×1=120이다. 종료 조건에서는 1을 반환한다.
개념 6. 재귀를 활용한 문자열 역순

문자열도 첫 문자와 나머지 문자열로 나눌 수 있다. 나머지 문자열을 먼저 뒤집고 첫 문자를 뒤에 붙이면 전체 문자열을 역순으로 만들 수 있다.

빈 문자열 또는 길이가 1인 문자열은 더 나눌 필요가 없으므로 종료 조건이 된다.

def reverse_text(text): if len(text) <= 1: return text return reverse_text(text[1:]) + text[0] print(reverse_text("STAR"))

코드 6 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ④, ⑤
나머지 문자열을 먼저 뒤집은 뒤 첫 문자를 뒤에 붙이므로 STAR는 RATS가 된다.
목표지향 통합 과제
자연수 n을 입력받아 n부터 1까지 출력하고, 1부터 n까지의 합과 n!을 각각 재귀 함수로 계산하는 프로그램을 작성해 보자. 각 함수의 종료 조건과 재귀 호출에서 매개변수가 어떻게 변하는지 주석으로 설명한다.

5. 학습 마무리 멘트

끝을 알아야 되돌아올 수 있다

한 편의 서사에는 시작과 반복되는 갈등이 있지만, 이야기를 완성하는 것은 끝입니다. 끝이 있기 때문에 독자는 지나온 장면을 새롭게 이해하고, 인물의 선택이 어떤 의미였는지 되돌아볼 수 있습니다.

재귀 함수도 같습니다. 계속 자신을 호출하는 힘만으로는 아무것도 완성되지 않습니다. 가장 작은 문제에 도달했을 때 멈추는 종료 조건이 있어야, 그동안 쌓인 호출들이 하나씩 답을 가지고 돌아옵니다.

철학에서 자기 성찰은 자신을 다시 바라보는 일입니다. 재귀도 자기 자신을 다시 호출하지만, 무한히 머무르지 않고 더 작고 분명한 질문으로 나아갑니다. 오늘 배운 종료 조건은 단지 코드의 문법이 아니라, 언제 멈추고 무엇을 답으로 삼을 것인가를 결정하는 사고의 기준입니다.
