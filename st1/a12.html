A 수준 수행과제 · 과학관 안전 대피 경로 분석 시스템

그래프 모델링 + BFS·DFS + 함수 모듈화 + 경로 복원 + 효율 분석

수행과제

과학관 전시실을 정점, 통로를 간선으로 하는 무방향 그래프를 구현한다. 출발 전시실에서 비상구까지 가장 적은 통로를 지나는 경로를 BFS로 구하고, DFS로 전체 연결 여부를 확인한다.

필수 조건 1 그래프 생성, BFS, DFS, 경로 복원을 각각 함수로 분리한다.
필수 조건 2존재하지 않는 정점과 연결되지 않은 비상구를 안전하게 처리한다.
필수 조건 3BFS와 DFS의 목적·방문 순서·자료 구조 차이를 설명한다.
필수 조건 4인접행렬과 인접리스트 중 선택한 표현의 근거를 제시한다.

예시 코드

from collections import deque def build_graph(n, edges): graph = [[] for _ in range(n)] for a, b in edges: graph[a].append(b) graph[b].append(a) return graph def shortest_path(graph, start, end): if not (0 <= start < len(graph) and 0 <= end < len(graph)): return [] q = deque([start]) parent = [-1] * len(graph) parent[start] = start while q: v = q.popleft() if v == end: break for nxt in graph[v]: if parent[nxt] == -1: parent[nxt] = v q.append(nxt) if parent[end] == -1: return [] path = [] cur = end while cur != start: path.append(cur) cur = parent[cur] path.append(start) path.reverse() return path def dfs(graph, v, visited): visited[v] = True for nxt in graph[v]: if not visited[nxt]: dfs(graph, nxt, visited) edges = [(0,1), (0,2), (1,3), (2,3), (3,4), (4,5)] graph = build_graph(6, edges) print(shortest_path(graph, 0, 5)) visited = [False] * len(graph) dfs(graph, 0, visited) print(all(visited))

상세 설명

build_graph()는 무방향 간선을 양쪽 정점의 인접리스트에 저장한다. shortest_path()는 큐를 사용해 가까운 정점부터 방문하고, 각 정점의 부모를 기록하여 도착점에서 출발점까지 경로를 역추적한다. dfs()는 재귀 호출로 한 경로를 깊게 방문하며 모든 정점의 방문 여부를 통해 그래프의 연결성을 확인한다.

비가중 그래프에서 BFS는 출발점에서 사용한 간선 수가 작은 순서로 정점을 방문하므로 가장 적은 통로를 지나는 경로를 찾을 수 있다. 인접리스트는 실제 연결된 통로만 저장하므로 전시실 수에 비해 통로 수가 적은 경우 공간 면에서 유리하다.

정답: ①, ③, ⑤
parent는 경로 복원을 위한 이전 정점을 저장하며 DFS는 재귀 또는 스택으로 구현할 수 있다.

B 수준 수행과제 · 실험 요청 처리와 실행 취소 시스템

큐 + 스택 + 함수 분리 + 빈 구조 처리

수행과제

과학 실험실의 측정 요청은 접수 순서대로 처리하고, 완료된 작업은 가장 최근 작업부터 취소할 수 있는 프로그램을 작성한다.

필수 조건 1요청 대기열은 큐로 구현한다.
필수 조건 2완료 기록은 스택으로 구현한다.
필수 조건 3접수, 처리, 취소 기능을 함수로 분리한다.
필수 조건 4빈 큐와 빈 스택을 안전하게 처리한다.

예시 코드

from collections import deque waiting = deque() completed = [] def request(name): waiting.append(name) def process(): if not waiting: return "대기 요청 없음" job = waiting.popleft() completed.append(job) return job + " 처리 완료" def undo(): if not completed: return "취소할 작업 없음" job = completed.pop() waiting.appendleft(job) return job + " 처리 취소" request("온도 측정") request("산도 측정") print(process()) print(process()) print(undo()) print(list(waiting)) print(completed)

상세 설명

waiting은 먼저 접수된 요청을 먼저 처리해야 하므로 큐로 구성한다. completed는 가장 최근에 완료한 작업을 먼저 취소해야 하므로 스택으로 구성한다. process()는 큐의 앞에서 요청을 꺼내 완료 스택에 넣고, undo()는 완료 스택의 top을 꺼내 대기열 앞에 되돌린다.

서로 다른 처리 순서를 하나의 프로그램에서 동시에 관리하는 것이 핵심이다. 삭제 전에 구조가 비어 있는지 검사하여 오류를 예방한다.

정답: ①, ②, ④

C 수준 수행과제 · 재귀와 반복으로 자연수 합 비교하기

함수 + 반복 구조 + 재귀 구조 + 실행 결과 비교

수행과제

1부터 n까지의 합을 반복 함수와 재귀 함수로 각각 구현하고, 두 함수의 결과가 같은지 확인한다.

필수 조건 1반복 함수에서 누적 변수를 사용한다.
필수 조건 2재귀 함수에 종료 조건을 작성한다.
필수 조건 3n=1, 5, 10을 입력하여 결과를 비교한다.
필수 조건 4두 방식의 종료 원리 차이를 설명한다.

예시 코드

def sum_iter(n): total = 0 for value in range(1, n + 1): total += value return total def sum_rec(n): if n == 0: return 0 return n + sum_rec(n - 1) for n in [1, 5, 10]: a = sum_iter(n) b = sum_rec(n) print(n, a, b, a == b)

상세 설명

sum_iter()는 total에 1부터 n까지 값을 누적한다. sum_rec()는 현재 n과 더 작은 문제 sum_rec(n-1)의 결과를 더한다. n이 0이면 0을 반환하여 재귀 호출을 종료한다.

반복 구조는 반복 범위를 모두 처리하면 끝나고, 재귀 구조는 종료 조건에 도달한 뒤 호출 순서의 반대로 복귀한다. 동일한 문제를 서로 다른 구조로 구현하고 결과를 비교하는 것이 핵심이다.

C 수행과제 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ③, ⑤
sum_iter(5)는 15이며 재귀 호출에서는 n이 1씩 감소한다.

D 수준 수행과제 · 큐와 스택의 상태 추적 프로그램

기본 연산 구별 + 실행 결과 추적

수행과제

같은 자료 A, B, C를 큐와 스택에 넣고 각각 하나씩 삭제한 뒤 남은 상태를 출력한다.

필수 조건 1큐에는 deque를 사용한다.
필수 조건 2스택에는 리스트를 사용한다.
필수 조건 3삭제된 값과 남은 상태를 출력한다.
필수 조건 4선입선출과 후입선출을 설명한다.

예시 코드

from collections import deque queue = deque() stack = [] for value in ["A", "B", "C"]: queue.append(value) stack.append(value) q_value = queue.popleft() s_value = stack.pop() print("큐 삭제:", q_value) print("큐 상태:", list(queue)) print("스택 삭제:", s_value) print("스택 상태:", stack)

상세 설명

큐에는 A, B, C가 들어온 순서대로 저장되며 popleft()를 실행하면 가장 먼저 들어온 A가 삭제된다. 스택에서는 pop()을 실행하면 가장 나중에 들어온 C가 삭제된다.

연산 뒤 큐에는 B, C가 남고 스택에는 A, B가 남는다. 자료 구조의 상태를 단계별로 기록하면 실행 결과를 정확히 예측할 수 있다.

정답: ①, ③, ④

E 수준 수행과제 · 함수 호출과 트리 관계 확인하기

수행과제

간단한 함수 호출 코드와 트리 자료를 실행하고, 출력 결과와 부모·자식·리프 관계를 확인한다.

필수 조건 1함수 정의와 호출을 구별한다.
필수 조건 2트리의 루트와 리프를 찾는다.
필수 조건 3코드를 그대로 실행하고 결과를 기록한다.
필수 조건 4교사의 안내에 따라 한 부분을 수정한다.

예시 코드

def greet(name): return name + " 학생, 시작합니다." print(greet("민수")) tree = { "과학": ["물리", "화학"], "물리": [], "화학": [] } print("루트:", "과학") print("과학의 자식:", tree["과학"]) print("리프:", [x for x in tree if not tree[x]])

상세 설명

greet 함수는 이름을 매개변수로 받아 문자열을 반환한다. 함수는 정의만으로 실행되지 않으며 greet("민수")처럼 호출할 때 본문이 실행된다.

트리에서 ‘과학’은 시작 정점인 루트이고 ‘물리’, ‘화학’은 과학의 자식이다. 자식 목록이 비어 있으므로 물리와 화학은 리프이다.

3. 수행평가 마무리 성찰

결과보다 중요한 것은 선택의 이유이다

같은 문제를 해결하더라도 어떤 학생은 반복문을, 어떤 학생은 재귀 함수를 선택할 수 있습니다. 어떤 관계는 그래프로, 어떤 계층은 트리로 표현할 수 있습니다. 중요한 것은 단지 실행되는 코드를 제출하는 것이 아닙니다.

왜 이 구조를 선택했는지, 어떤 입력에서 오류가 날 수 있는지, 더 나은 방법은 무엇인지 설명하는 과정에서 프로그램은 하나의 사고 결과가 됩니다.

좋은 수행평가는 답을 보여 주는 데서 끝나지 않고, 답에 도달한 생각의 구조를 드러냅니다.

1·2단원 성취수준 A~E에 따른 수행과제, 예시 코드, 상세 설명, 5지선다형 및 단답형 평가를 포함한 12차시 수행평가 자료이다.
