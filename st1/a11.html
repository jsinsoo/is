물리학의 법칙은 하나의 식으로 끝나지 않고 실험과 측정, 해석으로 연결됩니다. 생명과학의 세포는 개별 기관이 아니라 서로 관계를 맺는 체계이며, 천문학의 별도 은하와 우주망 속에서 의미를 가집니다.

지금까지 학습한 함수, 재귀, 큐, 스택, 그래프, 트리도 서로 떨어진 개념이 아닙니다. 함수는 문제를 역할별로 나누고, 재귀는 작은 문제를 다시 호출하며, 스택은 그 호출의 복귀를 기억합니다. 큐는 BFS를 만들고, 스택과 재귀는 DFS를 만듭니다. 그래프와 트리는 이 탐색이 움직이는 관계의 공간입니다.

오늘은 새로운 개념을 더하는 시간이 아니라, 배운 지식 사이의 연결을 발견하여 하나의 문제 해결 체계로 완성하는 시간입니다.

3. Ⅰ단원 프로그래밍 핵심 정리

3-1. 함수
  • 정의: def로 실행할 명령을 이름 아래 묶는다.
  • 호출: 함수 이름과 괄호로 실제 실행한다.
  • 매개변수: 함수가 입력값을 받는 변수이다.
  • 인수: 호출할 때 전달하는 실제 값이다.
  • 반환값: return으로 호출한 곳에 결과를 돌려준다.
  • 지역 변수: 함수 내부 범위에서 사용한다.
  • 전역 변수: 함수 밖에서 정의하며, 변경 시 global이 필요할 수 있다.
def analyze(data): minimum = min(data) maximum = max(data) return minimum, maximum low, high = analyze([3, 8, 2, 9]) print(low, high)
3-2. 재귀 함수
  • 함수가 자기 자신을 호출한다.
  • 현재 문제를 같은 형태의 더 작은 문제로 바꾼다.
  • 반드시 종료 조건에 도달해야 한다.
  • 호출은 깊어지고, 복귀는 역순으로 이루어진다.
  • 단일 호출과 다중 호출을 구별한다.
  • 다중 호출에서는 중복 계산과 호출 횟수 증가에 주의한다.
def factorial(n): if n <= 1: return 1 return n * factorial(n - 1) print(factorial(5))

4-2. 그래프
  • 정점: 대상, 간선: 관계
  • 방향 그래프: 간선의 방향을 구별
  • 가중 그래프: 거리·비용·시간 등을 간선에 저장
  • 인접행렬: 연결 확인이 쉽지만 n² 공간이 필요
  • 인접리스트: 실제 이웃만 저장하여 희소 그래프에 유리
  • 방문 배열: 순환과 중복 방문을 방지
4-3. 트리
  • 연결되고 순환이 없는 그래프의 특별한 형태로 볼 수 있다.
  • 루트, 부모, 자식, 형제, 리프, 서브트리, 깊이, 높이로 계층을 설명한다.
  • 전위 순회: 루트→왼쪽→오른쪽
  • 중위 순회: 왼쪽→루트→오른쪽
  • 후위 순회: 왼쪽→오른쪽→루트
  • 재귀 함수는 트리 순회를 자연스럽게 표현한다.
4-4. BFS와 DFS
탐색핵심 구조방문 방식대표 활용
BFS큐가까운 정점부터 층별 방문비가중 최단 거리, 단계 탐색

5. 1·2단원 통합 핵심 코드

코드 1. 함수와 반복 구조

함수는 문제를 기능별로 분리하고, 반복문은 자료를 순차적으로 처리한다.

def average(data): total = 0 for value in data: total += value return total / len(data) print(average([10, 20, 30]))

옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ⑤
total은 지역 변수이며 평균 20.0을 반환한다.
코드 2. 재귀 함수와 호출 스택

재귀 함수는 종료 조건에 도달한 뒤 역순으로 복귀한다.

def sum_rec(n): if n == 0: return 0 return n + sum_rec(n - 1) print(sum_rec(4))

옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ④
4+3+2+1+0으로 계산하며 단일 호출 재귀이다.
코드 3. 큐와 스택의 출력 순서

같은 자료도 큐와 스택의 삭제 순서가 다르다.

from collections import deque q = deque(["A", "B", "C"]) s = ["A", "B", "C"] print(q.popleft()) print(s.pop())

옳은 것을 모두 고르시오. (3개)

정답: ②, ③, ⑤
큐는 A, 스택은 C를 먼저 꺼낸다.
코드 4. 인접리스트 그래프

무방향 그래프는 양쪽 정점의 이웃 목록에 서로를 기록한다.

n = 4 edges = [(0,1), (0,2), (1,3)] graph = [[] for _ in range(n)] for a, b in edges: graph[a].append(b) graph[b].append(a) print(graph)

옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ④
정점별 이웃 목록을 저장하는 인접리스트이다.
코드 5. BFS

BFS는 큐를 사용하여 가까운 정점부터 방문한다.

from collections import deque def bfs(graph, start): visited = [False] * len(graph) q = deque([start]) visited[start] = True order = [] while q: v = q.popleft() order.append(v) for nxt in graph[v]: if not visited[nxt]: visited[nxt] = True q.append(nxt) return order

옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ⑤
popleft는 먼저 들어온 정점을 꺼내며 visited는 중복 방문을 막는다.
코드 6. 재귀 DFS와 트리 순회

재귀 DFS는 현재 정점을 방문하고 방문하지 않은 이웃으로 깊게 이동한다. 트리 순회도 같은 원리이다.

def dfs(graph, v, visited, order): visited[v] = True order.append(v) for nxt in graph[v]: if not visited[nxt]: dfs(graph, nxt, visited, order)

옳은 것을 모두 고르시오. (3개)

정답: ②, ④, ⑤
재귀 DFS는 스택 구조로 한 경로를 깊게 탐색한다.

10. 학습 마무리 멘트

배움은 지식을 모으는 일이 아니라 연결하는 일이다

도서관의 책은 한 권씩 떨어져 있지만, 독자는 서로 다른 책에서 얻은 생각을 연결해 자신만의 지도를 만듭니다. 음악의 음표도 하나씩 놓여 있을 때는 소리일 뿐이지만, 순서와 관계가 생기면 한 곡이 됩니다.

함수와 재귀, 큐와 스택, 그래프와 트리는 서로 다른 장의 개념이지만, 문제를 나누고 기억하고 연결하고 탐색하는 하나의 사고 체계를 이룹니다. 시험은 이 개념들을 외웠는지 확인하는 시간이 아니라, 새로운 문제에서 적절한 연결을 찾을 수 있는지 확인하는 시간입니다.

오늘의 정리는 끝이 아니라, 흩어진 지식을 하나의 이해로 바꾸는 시작입니다.
