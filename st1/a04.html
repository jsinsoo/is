과학자가 같은 현상을 여러 모형으로 설명하는 이유

물리학에서는 같은 운동을 힘의 관점으로도, 에너지의 관점으로도 설명합니다. 화학에서는 반응을 입자의 충돌로 보기도 하고, 에너지 변화로 해석하기도 합니다. 생명과학자는 개체의 변화와 유전자 수준의 변화를 서로 다른 모형으로 살펴봅니다. 천문학에서도 행성의 위치를 직접 계산하는 방식과 반복적인 수치 계산 방식이 함께 사용됩니다.

서로 다른 설명이 같은 현상을 다룬다고 해서 어느 하나가 항상 옳고 다른 하나가 항상 틀린 것은 아닙니다. 어떤 모형이 더 이해하기 쉬운지, 어떤 계산이 더 빠른지, 어떤 상황에서 오류가 적은지를 비교해야 합니다.

4. 개념 및 상세 설명 · 관련 코드 · 코드별 확인 문제

개념 1. 반복 구조와 재귀 구조의 기본 비교

반복 구조는 조건이 참인 동안 같은 명령을 되풀이한다. 반복 변수와 누적 변수를 사용하며, 반복 조건이 거짓이 되면 종료한다.

재귀 구조는 함수가 자신을 호출하면서 문제 크기를 줄인다. 종료 조건에 도달한 뒤 호출한 순서의 반대로 복귀한다.

반복은 대체로 호출 스택을 추가로 사용하지 않아 메모리 측면에서 유리하고, 재귀는 문제의 자기 유사 관계를 간결하게 표현하는 데 유리하다.

def count_iter(n): while n > 0: print(n) n -= 1 def count_rec(n): if n == 0: return print(n) count_rec(n - 1) count_iter(3) count_rec(3)

코드 1 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ⑤
반복문은 while 조건으로, 재귀 함수는 n==0 종료 조건으로 멈춘다.
개념 2. 1부터 n까지의 합: 누적과 복귀

반복 구조에서는 total 변수에 값을 차례로 더한다. 재귀 구조에서는 작은 문제의 반환값에 현재 n을 더한다.

결과는 같지만 계산이 만들어지는 과정은 다르다. 반복은 앞으로 진행하면서 누적하고, 재귀는 가장 작은 문제에 도달한 뒤 복귀하면서 결과를 결합한다.

def sum_iter(n): total = 0 for i in range(1, n + 1): total += i return total def sum_rec(n): if n == 0: return 0 return n + sum_rec(n - 1) print(sum_iter(5), sum_rec(5))

코드 2 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ③, ④
두 함수 모두 1+2+3+4+5=15를 반환하며, 재귀 호출은 n-1 방향으로 진행한다.
개념 3. 팩토리얼의 반복·재귀 구현

팩토리얼은 반복 구조에서는 1부터 n까지 차례로 곱하고, 재귀 구조에서는 n! = n × (n-1)! 관계를 이용한다.

재귀 표현은 수학적 정의와 닮아 이해하기 쉽지만, n이 매우 크면 호출 깊이 제한을 고려해야 한다.

def fact_iter(n): result = 1 for i in range(2, n + 1): result *= i return result def fact_rec(n): if n <= 1: return 1 return n * fact_rec(n - 1) print(fact_iter(5), fact_rec(5))

코드 3 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ⑤
곱셈 누적의 항등원은 1이며, 5!은 120이다.
개념 4. 최대공약수와 유클리드 알고리즘

유클리드 알고리즘은 두 수 a, b의 최대공약수가 b와 a를 b로 나눈 나머지의 최대공약수와 같다는 관계를 이용한다.

나머지가 0이 되면 현재 b가 최대공약수이다. 같은 알고리즘을 while 반복문과 재귀 함수로 모두 표현할 수 있다.

def gcd_iter(a, b): while b != 0: a, b = b, a % b return a def gcd_rec(a, b): if b == 0: return a return gcd_rec(b, a % b) print(gcd_iter(48, 18)) print(gcd_rec(48, 18))

코드 4 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ④
48과 18의 최대공약수는 6이며, 나머지가 0이 될 때 종료한다.
개념 5. 피보나치수: 같은 결과, 다른 효율

단순 재귀 피보나치 함수는 정의를 그대로 표현하지만 같은 값을 여러 번 계산한다. 반복 구조는 앞의 두 값을 변수에 저장해 한 번씩만 계산한다.

따라서 n이 커질수록 반복 구현이 일반적으로 더 빠르고 메모리 사용도 예측하기 쉽다. 이는 코드 길이만으로 효율을 판단해서는 안 된다는 뜻이다.

def fib_iter(n): a, b = 0, 1 for _ in range(n): a, b = b, a + b return a def fib_rec(n): if n <= 1: return n return fib_rec(n - 2) + fib_rec(n - 1) print(fib_iter(8), fib_rec(8))

코드 5 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ④, ⑤
F8은 21이다. 단순 재귀는 중복 계산이 많고 반복 구현은 필요한 값만 갱신한다.
개념 6. 구조 선택의 기준

반복과 재귀 중 어느 하나가 항상 우수한 것은 아니다. 문제의 구조, 입력 크기, 실행 환경, 가독성, 호출 깊이와 중복 계산을 함께 고려해야 한다.

계층 구조 탐색, 트리 순회, 하노이 탑처럼 작은 문제의 구조가 전체와 닮은 문제는 재귀가 자연스럽다. 단순 누적이나 매우 큰 반복 횟수는 반복문이 더 안전하고 효율적일 수 있다.

def power_iter(x, n): result = 1 for _ in range(n): result *= x return result def power_rec(x, n): if n == 0: return 1 return x * power_rec(x, n - 1) print(power_iter(2, 5)) print(power_rec(2, 5))

코드 6 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ⑤
2의 5제곱은 32이다. 적절한 구조는 문제와 실행 조건을 함께 고려해 선택한다.
목표지향 통합 과제
1부터 n까지의 합, 팩토리얼, 최대공약수 중 두 문제를 선택하여 반복 구조와 재귀 구조로 각각 구현한다. 실행 결과를 검증하고 코드 길이, 종료 방식, 메모리, 수행 시간, 가독성의 관점에서 비교표를 작성한다.

5. 학습 마무리 멘트

하나의 길만이 정답은 아니다

같은 산의 정상에 오르는 길은 하나가 아닙니다. 완만하지만 긴 길이 있고, 짧지만 가파른 길이 있습니다. 어느 길이 더 좋은지는 걷는 사람의 체력, 날씨, 시간, 목적에 따라 달라집니다.

예술에서도 같은 주제를 시인은 언어로, 화가는 색으로, 음악가는 소리로 표현합니다. 표현 방식은 다르지만 그 안에 담긴 의미는 서로 만날 수 있습니다. 프로그래밍의 반복과 재귀도 같은 문제를 서로 다른 사고의 언어로 표현합니다.

중요한 것은 익숙한 방식만 고집하는 것이 아니라, 문제를 살펴보고 가장 적절한 길을 선택하는 일입니다. 좋은 프로그래머는 코드를 많이 아는 사람이 아니라, 선택의 이유를 설명할 수 있는 사람입니다.
