5. 10차시 핵심 개념·코드 정리

1차시 · 상태 공간과 완전 탐색
성취기준 [12정과03-01]

상태 공간은 문제 해결 과정의 가능한 상태와 상태 전이를 구조화한 것이다. 상태·연산·초기 상태·목표 상태를 먼저 정의하면 탐색 문제를 명확하게 표현할 수 있다.

완전 탐색은 가능한 후보를 빠짐없이 확인하는 기준 전략이다. 정답을 놓치지 않는 장점이 있지만 후보 수가 2ⁿ, n!처럼 증가하면 실행량이 매우 커질 수 있다.

시험에서는 종료 조건·목표 조건의 차이, 중첩 반복 또는 재귀가 만드는 후보 수를 분석하는 문제가 중요하다.

def binary(s, n): if len(s) == n: print(s) return binary(s + "0", n) binary(s + "1", n) binary("", 3)

정답: ①, ②, ③

2차시 · 백트래킹과 가지치기
성취기준 [12정과03-02]

백트래킹은 선택을 진행하다가 적절한 해로 이어지기 어렵다고 판단되면 이전 상태로 돌아가 다른 선택을 시도한다. 대표 패턴은 선택 → 재귀 → 되돌리기이다.

가지치기는 정답이 될 수 없는 상태 아래의 탐색을 생략하는 것이다. 정답을 유지하면서 방문 상태 수를 줄이는 것이 핵심이며, 잘못된 가지치기는 실제 정답도 제거할 수 있다.

완전 탐색과 비교할 때는 정답의 동일성, 방문 상태 수, 실행 횟수 등을 함께 본다.

path = [] def perm(n): if len(path) == n: print(path) return for x in range(1, n + 1): if x not in path: path.append(x) perm(n) path.pop() perm(3)

3차시 · 탐욕법과 반례
성취기준 [12정과03-02], [12정과03-03]

탐욕법은 매 단계에서 현재 기준으로 가장 좋아 보이는 선택을 하고 그 선택을 되돌리지 않는다. 현재의 최선은 지역 최적, 문제 전체의 최선은 전체 최적이다.

탐욕법은 항상 전체 최적을 보장하지 않으므로 선택 기준을 검토하고 작은 입력에서 반례를 찾아 적용 조건을 확인해야 한다.

동전 [1,3,4]로 6을 만들 때 큰 동전부터 고르면 4+1+1의 3개지만, 3+3은 2개이므로 탐욕 규칙이 실패한다.

coins = [4, 3, 1] amount = 6 result = [] for coin in coins: while amount >= coin: amount -= coin result.append(coin) print(result)

4차시 · 분할정복: 이진 탐색과 병합 정렬
성취기준 [12정과03-04]

분할정복은 큰 문제를 작은 부분 문제로 분할하고, 각각 해결한 뒤 필요한 경우 결합한다.

이진 탐색은 정렬된 자료에서 중간값을 기준으로 필요한 절반만 다시 탐색하며 대표 복잡도는 O(log n)이다. 병합 정렬은 두 절반을 모두 정렬한 뒤 merge로 결합하며 대표 복잡도는 O(n log n)이다.

같은 분할정복이라도 해결하는 부분 문제 수와 결합 과정이 다르다는 점을 비교해야 한다.

def binary_search(a, target, left, right): if left > right: return -1 mid = (left + right) // 2 if a[mid] == target: return mid if target < a[mid]: return binary_search(a, target, left, mid - 1) return binary_search(a, target, mid + 1, right)

정답: ①, ②, ③
이진 탐색은 정렬 정보를 이용해 탐색 범위를 반복적으로 절반 수준으로 줄인다.
5차시 · 동적계획법
성취기준 [12정과03-05]

동적계획법(DP)은 같은 부분 문제가 반복되는 구조에서 이미 계산한 결과를 저장하고 재사용하여 중복 계산을 줄인다.

메모이제이션은 재귀 기반의 하향식 접근, 테이블 방식은 작은 상태부터 값을 채우는 상향식 접근이다.

핵심은 배열 사용 자체가 아니라 상태의 의미와 점화 관계를 정의하는 것이다.

def fib_dp(n): if n <= 1: return n dp = [0] * (n + 1) dp[1] = 1 for i in range(2, n + 1): dp[i] = dp[i-1] + dp[i-2] return dp[n]

6차시 · 시간 복잡도
성취기준 [12정과03-06]

시간 복잡도는 입력 크기 n이 커질 때 핵심 연산량이 어떻게 증가하는지 나타낸다. O(1), O(log n), O(n), O(n log n), O(n²)을 대표적으로 비교한다.

빅오는 정확한 초 단위 시간이 아니라 증가 경향이다. 실제 실행 시간은 환경의 영향을 받으므로 이론 복잡도와 함께 해석한다.

반복문의 중첩, 범위 절반 감소, 재귀 호출 횟수 등을 코드에서 읽는 연습이 중요하다.

def count_pairs(n): count = 0 for i in range(n): for j in range(n): count += 1 return count

def classify(score): if score < 0 or score > 100: return "입력 오류" if score >= 60: return "통과" return "보충" for x in [80, 60, 59, -1, 101]: print(x, classify(x))
