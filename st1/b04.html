2. 학습 시작 멘트

한 번에 해결하기 어려운 문제를 어떻게 작게 만들까?

수천 장의 카드에서 특정 숫자를 찾거나, 뒤섞인 많은 데이터를 정렬해야 한다고 생각해 봅시다. 처음부터 전체를 한꺼번에 다루면 문제는 복잡해 보입니다. 그러나 문제를 절반으로 나누고, 더 작은 문제를 같은 방식으로 다시 해결할 수 있다면 상황은 달라집니다.

분할정복은 큰 문제를 작게 만들고, 작은 문제의 답을 이용해 전체 답을 만드는 사고 방법입니다. 오늘은 정렬된 자료에서 탐색 범위를 절반씩 줄이는 이진 탐색과, 리스트를 절반씩 나누었다가 다시 합치는 병합 정렬을 비교합니다.

중요한 것은 코드를 외우는 것이 아니라 각 코드에서 무엇을 분할하는지, 언제 더 이상 나누지 않는지, 어느 부분 문제를 해결하는지, 결과를 어떻게 결합하는지를 찾는 것입니다.

4. 개념 및 상세 설명 · 관련 코드 · 코드별 확인 문제

개념 1. 분할정복의 세 단계: 분할 → 해결 → 결합

분할정복(divide and conquer)은 큰 문제를 더 작은 부분 문제로 분할하고, 각 부분 문제를 해결한 뒤, 필요한 경우 부분 결과를 결합하여 전체 문제의 답을 만드는 방법이다.

부분 문제는 원래 문제와 비슷한 구조를 가지므로 재귀함수와 자연스럽게 연결된다. 더 이상 나눌 필요가 없는 작은 문제는 기저 조건에서 직접 해결한다.

def divide_sum(a): if len(a) == 1: return a[0] mid = len(a) // 2 left = divide_sum(a[:mid]) right = divide_sum(a[mid:]) return left + right print(divide_sum([1, 2, 3, 4]))

리스트를 절반으로 나누어 재귀적으로 해결하고 두 부분의 합을 결합한다.
개념 2. 이진 탐색: 탐색 범위를 절반으로 줄이기

이진 탐색(binary search)은 정렬된 자료에서 가운데 값을 확인하고, 목표값이 있을 가능성이 있는 절반만 다시 탐색한다.

한 번 비교할 때마다 탐색 범위가 약 절반으로 줄어든다는 점이 핵심이다. 따라서 정렬 여부와 left, right, mid의 변화 과정을 정확히 이해해야 한다.

def binary_search(a, target, left, right): if left > right: return -1 mid = (left + right) // 2 if a[mid] == target: return mid if target < a[mid]: return binary_search(a, target, left, mid - 1) return binary_search(a, target, mid + 1, right) a = [2, 5, 8, 12, 16, 23, 38] print(binary_search(a, 16, 0, len(a)-1))

코드 2 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ③
정렬된 자료의 중간값과 비교하여 필요한 절반만 재귀적으로 탐색한다.
개념 3. 이진 탐색의 범위 추적

분할정복 코드를 이해하려면 결과만 보는 것이 아니라 부분 문제의 크기가 어떻게 변하는지 추적해야 한다.

아래 코드는 매 호출에서 현재 탐색 구간을 출력한다. 길이 8인 자료에서 목표값을 찾는 동안 전체 구간이 절반 크기의 구간으로 계속 줄어드는 모습을 확인할 수 있다.

def trace_search(a, target, left, right): print("범위:", left, "~", right) if left > right: return -1 mid = (left + right) // 2 if a[mid] == target: return mid elif target < a[mid]: return trace_search(a, target, left, mid - 1) else: return trace_search(a, target, mid + 1, right) a = [1, 3, 5, 7, 9, 11, 13, 15] print(trace_search(a, 13, 0, 7))

정답: ①, ②, ③
범위를 출력해 보면 이진 탐색이 매 단계에서 탐색 문제의 크기를 줄이는 과정을 직접 확인할 수 있다.
개념 4. 병합 정렬의 분할: 리스트를 절반씩 나누기

병합 정렬(merge sort)은 리스트를 절반으로 계속 나누어 길이 1의 리스트까지 만든 뒤, 정렬된 작은 리스트들을 다시 합쳐 전체를 정렬한다.

분할 단계에서는 가운데 위치를 기준으로 왼쪽과 오른쪽 부분 문제를 만들고, 두 부분에 같은 정렬 함수를 재귀적으로 적용한다.

def merge_sort(a): if len(a) <= 1: return a mid = len(a) // 2 left = merge_sort(a[:mid]) right = merge_sort(a[mid:]) return merge(left, right)

코드 4 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ③
길이가 1 이하이면 이미 정렬된 것으로 보고, 그보다 크면 두 부분으로 나누어 각각 정렬한다.
개념 5. 병합 정렬의 결합: 두 정렬 리스트 합치기

병합 정렬에서 결합은 두 개의 이미 정렬된 리스트를 하나의 정렬된 리스트로 만드는 과정이다.

두 리스트의 맨 앞 값을 비교하여 더 작은 값을 결과에 넣고, 한쪽 리스트를 모두 사용한 뒤에는 남은 원소를 그대로 이어 붙인다.

def merge(left, right): result = [] i = j = 0 while i < len(left) and j < len(right): if left[i] <= right[j]: result.append(left[i]) i += 1 else: result.append(right[j]) j += 1 result += left[i:] result += right[j:] return result print(merge([2, 7, 9], [1, 5, 8]))

정답: ①, ②, ③
병합은 두 정렬 리스트의 앞 원소를 비교하며 작은 값을 순서대로 결과에 넣는다.
개념 6. 이진 탐색과 병합 정렬의 분할정복 구조 비교

이진 탐색과 병합 정렬은 모두 문제 크기를 줄이지만 구조는 다르다. 이진 탐색은 비교 결과에 따라 한쪽 부분 문제만 해결한다. 병합 정렬은 두 부분 문제를 모두 해결한 뒤 결과를 병합한다.

따라서 분할정복을 단순히 “반으로 나누는 알고리즘”으로 기억하기보다, 어떻게 분할하고 어떤 부분을 해결하며 결과를 어떻게 결합하는가를 비교해야 한다.

# 이진 탐색 # 1. 가운데를 기준으로 분할 # 2. 필요한 한쪽만 해결 # 3. 별도의 복잡한 결합은 거의 없음 # 병합 정렬 # 1. 가운데를 기준으로 두 부분으로 분할 # 2. 왼쪽과 오른쪽을 모두 재귀적으로 해결 # 3. 두 정렬 결과를 merge로 결합 data = [8, 3, 6, 2, 7, 1, 5, 4] print(merge_sort(data))

코드 6 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ③
이진 탐색은 필요한 절반만 해결하고, 병합 정렬은 두 절반을 모두 해결하여 결합한다.
목표지향 통합 과제
정렬된 16개 숫자에서 특정 값을 찾는 선형 탐색과 이진 탐색의 비교 횟수를 기록해 보자. 이어서 8개의 숫자를 병합 정렬할 때 리스트가 어떻게 4→2→1 크기로 분할되고 다시 결합되는지 트리로 표현한다. 마지막으로 두 알고리즘을 분할 대상·해결하는 부분 문제 수·결합 과정의 세 기준으로 비교하자.

5. 학습 마무리 멘트

큰 문제를 해결하는 힘은 문제를 잘게 보는 데서 시작한다

분할정복은 단순히 데이터를 반으로 자르는 기술이 아닙니다. 큰 문제 속에서 같은 구조를 가진 작은 문제를 발견하고, 가장 작은 문제까지 내려가 해결한 뒤 전체 답으로 연결하는 사고 방식입니다.

이진 탐색은 중간값 비교를 이용해 필요 없는 절반을 버리고 한쪽 문제만 해결합니다. 병합 정렬은 두 절반을 모두 해결한 뒤 그 결과를 다시 병합합니다. 같은 분할정복이라도 문제에 따라 해결과 결합 방식이 달라집니다.

다음 차시에서는 또 다른 질문을 다룹니다. 부분 문제들이 서로 독립적이지 않고 같은 계산이 반복된다면, 이미 구한 답을 저장해서 다시 사용할 수 없을까? 이것이 동적계획법과 메모이제이션으로 이어집니다.
