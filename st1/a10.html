4. 개념 및 상세 설명 · 관련 코드 · 코드별 확인 문제

개념 1. 그래프와 트리의 관계

트리는 그래프의 한 종류이다. 일반적으로 트리는 모든 정점이 연결되어 있고 순환이 없으며, 루트를 정하면 부모·자식의 계층 관계를 표현할 수 있다.

일반 그래프는 순환이 있을 수 있고 여러 경로가 존재할 수 있으므로 방문한 정점을 기록해야 한다.

tree_edges = [(0,1), (0,2), (1,3)] graph_edges = [(0,1), (1,2), (2,0), (2,3)] print("트리 간선 수:", len(tree_edges)) print("그래프 간선 수:", len(graph_edges)) print("그래프에는 0-1-2-0 순환이 있음")

코드 1 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ⑤
트리는 연결되고 순환이 없는 그래프로 볼 수 있으며, 일반 그래프는 중복 방문을 막아야 한다.
개념 2. 방문 배열과 중복 방문 방지

그래프에는 여러 경로와 순환이 있을 수 있다. 방문 여부를 기록하지 않으면 같은 정점을 반복 처리하거나 무한히 순환할 수 있다.

visited[v]를 True로 바꾸면 해당 정점을 이미 처리했음을 나타낸다.

graph = [ [1, 2], [0, 2], [0, 1, 3], [2] ] visited = [False] * len(graph) visited[0] = True for nxt in graph[0]: if not visited[nxt]: visited[nxt] = True print(visited)

출력: [True, True, True, False]

코드 2 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ④
visited는 정점별 방문 여부를 저장하며 순환과 중복 처리를 방지한다.
개념 3. 큐를 이용한 너비 우선 탐색

너비 우선 탐색(BFS)은 시작 정점에서 가까운 정점부터 층별로 방문한다. 먼저 발견한 정점을 먼저 처리해야 하므로 큐를 사용한다.

정점을 큐에 넣을 때 방문 표시를 하면 같은 정점이 여러 번 큐에 들어가는 것을 막을 수 있다.

from collections import deque graph = [ [1, 2], [0, 3, 4], [0, 5], [1], [1], [2] ] def bfs(start): visited = [False] * len(graph) q = deque([start]) visited[start] = True order = [] while q: v = q.popleft() order.append(v) for nxt in graph[v]: if not visited[nxt]: visited[nxt] = True q.append(nxt) return order print(bfs(0))

출력: [0, 1, 2, 3, 4, 5]

코드 3 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ③, ⑤
BFS는 큐를 사용하며 시작점과의 거리가 작은 정점부터 방문한다.
개념 4. 재귀 함수를 이용한 깊이 우선 탐색

깊이 우선 탐색(DFS)은 한 경로를 가능한 깊게 따라간 뒤 더 갈 곳이 없으면 이전 정점으로 되돌아온다.

재귀 호출의 호출 스택이 현재 경로를 기억하므로 DFS를 자연스럽게 표현할 수 있다.

graph = [ [1, 2], [0, 3, 4], [0, 5], [1], [1], [2] ] def dfs(v, visited, order): visited[v] = True order.append(v) for nxt in graph[v]: if not visited[nxt]: dfs(nxt, visited, order) visited = [False] * len(graph) order = [] dfs(0, visited, order) print(order)

출력: [0, 1, 3, 4, 2, 5]

코드 4 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ④
DFS는 0-1-3 방향으로 깊게 진행한 뒤 되돌아오며 방문 배열이 필요하다.
개념 5. 스택을 이용한 반복형 DFS

DFS는 재귀 함수뿐 아니라 명시적인 스택으로도 구현할 수 있다. 스택에서 최근에 넣은 정점을 먼저 꺼내므로 한 경로를 깊게 탐색한다.

이웃을 역순으로 넣으면 재귀 DFS와 비슷한 방문 순서를 만들 수 있다.

graph = [ [1, 2], [0, 3, 4], [0, 5], [1], [1], [2] ] def dfs_stack(start): visited = [False] * len(graph) stack = [start] order = [] while stack: v = stack.pop() if visited[v]: continue visited[v] = True order.append(v) for nxt in reversed(graph[v]): if not visited[nxt]: stack.append(nxt) return order print(dfs_stack(0))

출력: [0, 1, 3, 4, 2, 5]

코드 5 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ⑤
반복형 DFS는 스택을 사용하며 이웃의 저장 순서가 탐색 순서에 영향을 준다.
개념 6. 연결 요소와 경로 존재 확인

서로 경로로 연결된 정점들의 집합을 연결 요소라고 한다. 방문하지 않은 정점에서 새 탐색을 시작할 때마다 연결 요소 수가 하나 증가한다.

BFS 또는 DFS를 이용해 출발점에서 도착점에 도달할 수 있는지도 확인할 수 있다.

graph = [ [1], [0, 2], [1], [4], [3], [] ] def mark(start, visited): stack = [start] visited[start] = True while stack: v = stack.pop() for nxt in graph[v]: if not visited[nxt]: visited[nxt] = True stack.append(nxt) visited = [False] * len(graph) count = 0 for v in range(len(graph)): if not visited[v]: mark(v, visited) count += 1 print(count)

출력: 3

코드 6 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ④, ⑤
연결 요소는 {0,1,2}, {3,4}, {5}의 세 개이다.
목표지향 통합 과제
과학관 전시실 연결 지도를 인접리스트로 구현한다. BFS로 출발 전시실에서 가까운 순서의 방문 결과를 구하고, DFS로 한 경로를 깊게 탐색한 결과를 구한다. 이어서 전체 연결 요소 수와 특정 전시실까지의 도달 가능 여부를 출력하고 두 탐색의 차이를 설명한다.

5. 학습 마무리 멘트

넓게 바라보는 길과 깊이 들어가는 길

어떤 사람은 한 시대의 여러 작품을 넓게 살피며 공통된 흐름을 발견하고, 어떤 사람은 한 작품을 깊이 읽으며 한 문장 속에 숨은 의미를 찾습니다. 두 탐구 방식은 서로 경쟁하지 않습니다. 질문이 다르기 때문에 길이 다른 것입니다.

너비 우선 탐색은 가까운 가능성을 차례로 확인하고, 깊이 우선 탐색은 하나의 가능성을 끝까지 따라갑니다. 삶에서도 때로는 주변을 고르게 살펴야 하고, 때로는 한 문제에 깊이 몰입해야 합니다.

좋은 탐색은 많이 방문하는 것이 아니라, 목적에 맞는 순서로 질문을 이어 가는 일입니다.
