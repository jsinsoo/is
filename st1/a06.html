2. 학습 시작 멘트

실험 기록과 로봇 명령: 가장 최근의 상태를 되돌리는 구조

화학 실험에서 시약을 잘못 넣었다면 가장 최근에 수행한 단계를 먼저 되돌려야 합니다. 생명과학의 현미경 관찰에서도 확대 단계를 여러 번 바꾼 뒤 이전 화면으로 돌아가려면 가장 마지막 설정부터 역순으로 복원해야 합니다.

공학에서는 로봇이 여러 명령을 차례로 실행하다 문제가 생기면 가장 최근 명령부터 취소합니다. 수학의 괄호 계산에서도 가장 안쪽에서 열린 괄호가 먼저 닫혀야 식의 구조가 올바릅니다. 컴퓨터가 함수를 여러 번 호출할 때도 가장 최근에 호출한 함수가 먼저 끝나고 이전 함수로 돌아갑니다.

이러한 상황의 공통점은 나중에 들어온 것이 먼저 나온다는 것입니다. 오늘 학습할 스택은 시간의 역순을 안전하게 관리하는 자료 구조입니다.

4. 개념 및 상세 설명 · 관련 코드 · 코드별 확인 문제

개념 1. 스택과 후입선출

스택은 나중에 들어온 자료가 먼저 나가는 후입선출 방식의 선형 데이터 구조이다. 자료의 삽입과 삭제는 모두 스택의 한쪽 끝인 top에서 이루어진다.

자료를 10, 20, 30 순서로 넣으면 삭제 순서는 30, 20, 10이다. 접시 쌓기, 실행 취소, 브라우저 뒤로 가기, 함수 호출 관리와 같은 상황에 활용된다.

LIFOtoppush·pop
stack = [] stack.append(10) stack.append(20) stack.append(30) print(stack) print(stack.pop()) print(stack)

출력: [10, 20, 30] → 30 → [10, 20]

코드 1 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ④
가장 최근에 삽입한 30이 먼저 삭제되고 10, 20이 남는다.
개념 2. top과 기본 연산

push는 top에 자료를 삽입하고, pop은 top의 자료를 삭제하여 반환한다. peek 또는 top 확인은 자료를 삭제하지 않고 가장 위의 값을 읽는다.

파이썬 리스트에서는 stack[-1]로 top을 확인하고 len(stack)으로 크기를 구할 수 있다.

stack = [5, 8, 12] top = stack[-1] size = len(stack) is_empty = len(stack) == 0 print(top) print(size) print(is_empty)

코드 2 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ⑤
stack[-1]은 마지막 원소를 확인할 뿐 삭제하지 않는다.
개념 3. 리스트로 스택 연산 구현하기

파이썬 리스트는 마지막 위치의 삽입과 삭제를 지원하므로 스택을 간단히 구현할 수 있다. append()는 push, 인수 없는 pop()은 pop 역할을 한다.

스택 연산을 함수로 분리하면 기능을 재사용하고 테스트하기 쉽다.

def push(stack, value): stack.append(value) def pop_stack(stack): if not stack: return None return stack.pop() s = [] push(s, "A") push(s, "B") print(pop_stack(s)) print(s)

코드 3 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ③, ⑤
B가 가장 나중에 삽입되어 먼저 삭제된다. 빈 스택이면 None을 반환한다.
개념 4. 빈 스택과 언더플로 방지

빈 스택에서 pop을 수행하면 삭제할 자료가 없어 오류가 발생한다. 이를 스택 언더플로 상황이라고 설명할 수 있다.

따라서 if not stack으로 비어 있는지 먼저 확인해야 한다. 안전한 프로그램은 정상 상황뿐 아니라 빈 구조와 같은 경계 상황도 처리한다.

def safe_pop(stack): if not stack: return "스택이 비어 있음" return stack.pop() stack = [] print(safe_pop(stack)) stack.append(7) print(safe_pop(stack))

코드 4 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ④
not stack은 스택이 비었을 때 참이다.
개념 5. 문자열 뒤집기

문자열의 문자를 차례로 스택에 넣은 뒤 하나씩 꺼내면 입력 순서의 반대로 나온다. 이는 스택의 후입선출 원리를 직접 활용한 예이다.

문자열 뒤집기는 스택의 동작을 이해하기 좋은 기본 문제이며, 이후 수식 변환과 경로 복원 문제로 확장할 수 있다.

def reverse_text(text): stack = [] for ch in text: stack.append(ch) result = "" while stack: result += stack.pop() return result print(reverse_text("SCIENCE"))

코드 5 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ④, ⑤
SCIENCE의 역순은 ECNEICS이며, 마지막 문자부터 꺼낸다.
개념 6. 괄호 검사와 함수 호출 스택

여는 괄호를 만나면 스택에 넣고, 닫는 괄호를 만나면 가장 최근의 여는 괄호를 꺼내 짝을 맞춘다. 닫는 괄호가 나왔는데 스택이 비었거나, 처리가 끝난 뒤 여는 괄호가 남으면 올바르지 않다.

이 원리는 함수 호출에도 적용된다. 가장 최근에 호출된 함수가 먼저 종료되어 이전 함수로 복귀하므로 호출 스택은 후입선출 구조로 동작한다.

def valid_parentheses(text): stack = [] for ch in text: if ch == "(": stack.append(ch) elif ch == ")": if not stack: return False stack.pop() return len(stack) == 0 print(valid_parentheses("(())")) print(valid_parentheses("(()"))

코드 6 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ⑤
(())는 올바르고 (()는 여는 괄호가 하나 남으므로 False이다.
목표지향 통합 과제
실험 절차를 문자열 목록으로 입력받아 스택에 저장하고, 가장 최근 절차부터 되돌리는 프로그램을 작성한다. 이어서 소괄호가 올바르게 짝지어진 실험식인지 검사하고, 빈 스택에서도 오류가 발생하지 않도록 구현한다.

5. 학습 마무리 멘트

되돌아간다는 것은 지우는 일이 아니다

화가는 마지막에 그은 선을 지우며 그림 전체의 균형을 다시 찾고, 작가는 가장 최근에 쓴 문장을 고치며 이야기의 흐름을 바로잡습니다. 음악가도 방금 연주한 구절을 되짚으며 다음 소리를 더 정확하게 만듭니다.

스택의 되돌리기는 과거를 없애는 일이 아니라, 지나온 과정을 순서대로 이해하는 일입니다. 가장 최근의 선택부터 차례로 살펴보기 때문에 어디에서 문제가 생겼는지 찾을 수 있습니다.

우리는 앞으로 나아갈 때만 배우는 것이 아닙니다. 때로는 한 단계씩 되돌아보며 더 나은 길을 발견합니다. 스택은 기억을 쌓는 구조이면서, 성찰을 가능하게 하는 구조입니다.
