2. 학습 시작 멘트

실험실의 대기열과 우주선의 긴급 복구

화학 분석실에서는 시료가 접수된 순서대로 장비에 들어가야 기록이 뒤섞이지 않습니다. 생명과학 실험에서도 배양 접시가 도착한 순서대로 검사되어야 시간 조건을 정확히 맞출 수 있습니다. 이런 상황은 큐와 닮았습니다.

반대로 우주선 제어 프로그램에서 최근에 적용한 설정 때문에 문제가 생겼다면 가장 마지막 설정부터 되돌려야 합니다. 로봇 팔의 동작을 복구하거나 수학식의 괄호를 검사할 때도 가장 최근 상태를 먼저 확인합니다. 이런 상황은 스택과 닮았습니다.

오늘의 핵심은 큐와 스택을 외우는 것이 아닙니다. 문제의 시간 방향을 읽고, 먼저 온 것을 먼저 처리할지, 가장 최근 것을 먼저 처리할지 판단하는 것입니다.

4. 개념 및 상세 설명 · 관련 코드 · 코드별 확인 문제

개념 1. 큐와 스택의 선택 기준

큐와 스택은 모두 자료를 순서대로 저장하는 선형 데이터 구조이다. 차이는 삭제 순서이다. 큐는 가장 먼저 들어온 자료를, 스택은 가장 나중에 들어온 자료를 먼저 꺼낸다.

‘대기’, ‘선착순’, ‘도착 순서’는 큐를, ‘최근’, ‘되돌리기’, ‘가장 안쪽’은 스택을 떠올리게 한다.

from collections import deque data = [1, 2, 3] q = deque(data) s = data.copy() print(q.popleft()) print(s.pop())

출력: 1, 3

코드 1 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ⑤
큐는 앞에서, 스택은 뒤에서 자료를 꺼낸다.
개념 2. 프린터 큐

프린터 작업은 기본적으로 들어온 순서대로 처리할 수 있다. 아래 코드는 작업 이름을 큐에 저장하고 앞에서부터 출력한다.

큐가 비어 있을 때까지 반복하며, popleft()로 현재 작업을 꺼낸다.

from collections import deque jobs = deque(["보고서", "그래프", "사진"]) order = [] while jobs: current = jobs.popleft() order.append(current) print(order)

코드 2 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ④
큐의 선입선출 원리에 따라 입력 순서가 유지된다.
개념 3. 카드 순환 문제

큐에서는 앞의 자료를 삭제한 뒤 다음 앞 자료를 뒤로 보내는 순환 처리를 구현할 수 있다. 카드 버리기 문제는 이 연산을 반복하는 대표 사례이다.

from collections import deque cards = deque([1, 2, 3, 4, 5]) while len(cards) > 1: cards.popleft() cards.append(cards.popleft()) print(cards[0])

출력: 2

코드 3 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ③, ⑤
카드가 하나 남으면 반복을 끝내며 결과는 2이다.
개념 4. 여러 종류의 괄호 검사

여는 괄호는 스택에 넣고, 닫는 괄호는 가장 최근의 여는 괄호와 종류가 맞는지 검사한다. 닫는 괄호가 먼저 나오거나 종류가 다르면 잘못된 식이다.

def valid_brackets(text): stack = [] pair = {")": "(", "]": "[", "}": "{"} for ch in text: if ch in "([{": stack.append(ch) elif ch in ")]}": if not stack or stack.pop() != pair[ch]: return False return not stack print(valid_brackets("{[()]}")) print(valid_brackets("([)]"))

코드 4 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ④
괄호의 개수뿐 아니라 중첩 순서와 종류가 모두 맞아야 한다.
개념 5. 후위 표기식 계산

후위 표기식은 연산자가 피연산자 뒤에 온다. 숫자는 스택에 넣고, 연산자를 만나면 스택에서 두 값을 꺼내 계산한 뒤 결과를 다시 넣는다.

뺄셈과 나눗셈은 먼저 꺼낸 값이 오른쪽 피연산자라는 점에 주의한다.

def postfix(tokens): stack = [] for token in tokens: if token.isdigit(): stack.append(int(token)) else: b = stack.pop() a = stack.pop() if token == "+": stack.append(a + b) elif token == "*": stack.append(a * b) return stack.pop() print(postfix(["2", "3", "+", "4", "*"]))

계산: (2+3)×4 = 20

코드 5 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ⑤
피연산자를 저장하고 최근 두 값을 꺼내 계산하는 스택 문제이다.
개념 6. 구조 선택과 경계 상황 검사

자료 구조를 선택한 뒤에는 빈 구조, 자료 한 개, 잘못된 입력과 같은 경계 상황을 확인해야 한다. 삭제 전에 비어 있는지 검사하고, 연산 뒤 상태가 문제의 규칙과 일치하는지 추적한다.

def choose_structure(problem): if "선착순" in problem or "대기" in problem: return "큐" if "최근" in problem or "되돌리기" in problem: return "스택" return "추가 분석 필요" print(choose_structure("선착순 대기 처리")) print(choose_structure("최근 작업 되돌리기"))

코드 6 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ④, ⑤
선착순·대기는 큐, 최근·되돌리기는 스택과 연결된다.
목표지향 통합 과제
‘실험 요청 대기열’과 ‘실험 절차 되돌리기’를 하나의 프로그램으로 작성한다. 요청은 큐에 저장해 선착순으로 처리하고, 완료된 절차는 스택에 저장해 최근 절차부터 취소할 수 있게 한다. 각 연산 뒤 자료 구조의 상태를 출력한다.

5. 학습 마무리 멘트

순서를 읽는다는 것

소설은 사건의 순서가 달라지면 의미가 달라지고, 음악은 같은 음이라도 연주되는 순서에 따라 전혀 다른 선율이 됩니다. 인간의 기억도 모든 일을 같은 방식으로 꺼내지 않습니다. 오래 기다린 약속을 먼저 지키기도 하고, 가장 최근의 실수를 먼저 되돌아보기도 합니다.

큐와 스택은 단순한 저장 상자가 아닙니다. 데이터가 가진 시간의 의미를 보존하는 방식입니다. 무엇을 먼저 꺼낼 것인가를 결정하는 순간, 우리는 문제의 가치와 규칙을 함께 선택합니다.
