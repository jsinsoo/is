2. 학습 시작 멘트

우주망원경과 함수: 거대한 과학을 움직이는 작은 역할들

천문학자는 망원경으로 얻은 빛을 곧바로 별의 온도라고 부르지 않습니다. 먼저 센서가 빛을 측정하고, 보정 장치가 잡음을 줄이고, 분석 과정이 파장별 세기를 계산하며, 마지막 단계가 별의 온도와 성분을 추정합니다. 하나의 거대한 연구가 여러 작은 역할로 나뉘어 정확하게 연결되는 것입니다.

물리 실험에서는 측정 함수가 힘과 가속도를 받아 값을 계산하고, 화학 실험에서는 농도 계산 과정이 부피와 몰수를 입력받아 결과를 내놓습니다. 생명과학에서는 DNA 서열을 분석하는 과정이 반복되는 규칙을 하나의 절차로 묶습니다. 공학에서는 센서 읽기, 제어 판단, 모터 작동을 각각 독립된 기능으로 구성합니다.

프로그래밍의 함수도 같습니다. 복잡한 문제를 의미 있는 작은 기능으로 나누고, 각 기능에 이름을 붙이며, 필요한 값을 전달하고 결과를 돌려받습니다. 오늘 우리는 코드 한 덩어리를 쓰는 사람이 아니라, 역할이 분명한 작은 지식 장치를 설계하는 사람이 됩니다.

4. 개념 및 상세 설명 · 관련 코드 · 코드별 확인 문제

개념 1. 함수의 정의와 호출

함수 정의는 실행할 명령들을 하나의 이름 아래 묶는 과정이다. def 다음에 함수 이름을 쓰고 괄호와 콜론을 붙인다. 함수 본문은 들여쓰기한다. 정의만으로 함수 본문이 실행되지는 않는다.

함수 호출은 정의된 함수 이름 뒤에 괄호를 붙여 실제로 실행하도록 요청하는 것이다. 함수는 먼저 정의되어 있어야 하며, 호출 시점에 함수 본문이 위에서 아래로 실행된다.

정의호출들여쓰기
def greet(): print("안녕하세요.") print("정보과학 수업을 시작합니다.") print("준비") greet() print("완료")

출력
준비 → 안녕하세요. → 정보과학 수업을 시작합니다. → 완료

코드 1 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ④
함수 정의는 실행할 내용을 등록하는 과정이며, 본문은 호출 시 실행된다. 호출은 실행 시점 기준으로 정의 이후에 이루어져야 한다.
개념 2. 함수의 호출과 복귀

프로그램이 함수를 호출하면 현재 실행 위치를 기억한 뒤 함수 본문으로 이동한다. 함수 본문이 끝나면 호출했던 다음 명령으로 복귀한다. 이 흐름을 이해하면 여러 함수가 연결된 코드의 실행 순서를 예측할 수 있다.

함수 안에서 다른 함수를 호출할 수도 있다. 이때 가장 안쪽에서 호출된 함수가 먼저 끝나고 바깥 함수로 돌아온다.

def measure(): print("2. 센서 측정") def experiment(): print("1. 실험 시작") measure() print("3. 실험 종료") print("0. 준비") experiment() print("4. 기록")

코드 2 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ⑤
measure 함수가 종료되면 experiment 함수의 호출 다음 줄로 복귀하며, experiment가 끝난 뒤 주 프로그램으로 돌아온다.
개념 3. 매개변수와 인수

매개변수는 함수가 사용할 입력값을 받기 위해 함수 정의에 작성하는 변수이다. 인수는 실제 호출할 때 전달하는 값이다. 같은 함수에 서로 다른 인수를 전달하면 동일한 계산 절차를 여러 상황에 재사용할 수 있다.

아래 함수에서 distance와 time은 매개변수이고, speed(150, 3)의 150과 3은 인수이다.

def speed(distance, time): value = distance / time print("속력:", value, "km/h") speed(150, 3) speed(90, 2)

코드 3 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ③, ④
150÷3은 50이고 90÷2는 45이다. 매개변수는 함수 정의에, 인수는 함수 호출에 작성한다.
개념 4. 반환값과 return

return은 함수가 계산한 결과를 호출한 곳으로 돌려준다. 반환된 값은 변수에 저장하거나 다른 계산에 바로 사용할 수 있다. return이 실행되면 그 함수의 실행은 즉시 끝나므로, 그 아래에 있는 같은 블록의 명령은 실행되지 않는다.

출력과 반환은 다르다. print()는 화면에 보여 주고, return은 값을 프로그램의 다음 계산에 넘긴다.

def celsius_to_kelvin(c): return c + 273.15 k1 = celsius_to_kelvin(0) k2 = celsius_to_kelvin(25) print(k1) print(k2 - k1)

코드 4 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ⑤
0℃는 273.15K, 25℃는 298.15K이므로 차이는 25.0이다. 반환값은 변수 저장과 후속 계산에 활용된다.
개념 5. 여러 값 반환과 함수 설계

함수는 쉼표로 구분하여 여러 값을 한 번에 반환할 수 있다. 호출한 쪽에서는 같은 개수의 변수로 나누어 받을 수 있다. 하나의 함수는 가능한 한 역할을 분명히 해야 하며, 함수 이름은 기능을 드러내도록 짓는 것이 좋다.

과학 데이터에서는 최솟값과 최댓값, 평균과 표준편차처럼 서로 관련된 결과를 함께 반환하면 유용하다.

def range_info(data): low = min(data) high = max(data) return low, high, high - low temperatures = [18.5, 21.0, 19.2, 23.3] minimum, maximum, spread = range_info(temperatures) print(minimum, maximum, spread)

코드 5 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ④
범위는 23.3-18.5=4.8이다. 파이썬에서는 여러 반환값을 여러 변수에 나누어 저장할 수 있다.
개념 6. 지역 변수와 전역 변수

지역 변수는 함수 안에서 만들어져 그 함수 안에서만 사용할 수 있다. 전역 변수는 함수 밖에서 만들어져 프로그램의 넓은 범위에서 읽을 수 있다.

함수 안에서 전역 변수의 값을 바꾸려면 global 선언이 필요하다. 그러나 전역 변수를 지나치게 사용하면 여러 함수가 같은 값을 바꾸어 오류를 찾기 어려워진다. 가능한 경우 매개변수와 반환값으로 데이터를 주고받는 설계가 더 안전하다.

total = 0 def add_measurement(value): global total local_value = value * 2 total += local_value return local_value a = add_measurement(3) b = add_measurement(4) print(a, b, total)

코드 6 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ④, ⑤
첫 호출에서 total은 6, 두 번째 호출 뒤 14가 된다. local_value는 함수 밖에서 직접 사용할 수 없는 지역 변수이다.
목표지향 통합 과제
물리 실험에서 측정한 거리와 시간을 받아 속력을 반환하는 함수, 여러 속력의 최솟값·최댓값을 반환하는 함수, 결과를 출력하는 함수를 각각 작성해 하나의 프로그램으로 연결해 보자.

5. 학습 마무리 멘트

좋은 함수는 작은 약속이다

한 편의 교향곡은 수많은 악기가 동시에 아무 소리나 내는 것이 아닙니다. 바이올린은 선율을 맡고, 타악기는 리듬을 세우며, 지휘자는 각 역할이 정확한 시점에 만나도록 이끕니다. 문학에서도 한 문장은 하나의 생각을 담고, 여러 문장이 모여 한 장면과 세계를 만듭니다.

함수 역시 작은 약속입니다. “이 값을 주면, 이 역할을 수행하고, 이 결과를 돌려주겠다.”라는 약속입니다. 이름이 분명하고 역할이 선명한 함수는 다른 사람과 협력할 수 있는 코드가 됩니다. 철학자들이 복잡한 세계를 개념으로 나누어 이해했듯, 프로그래머는 복잡한 문제를 함수로 나누어 이해합니다.

오늘 만든 짧은 함수 하나는 단지 코드 몇 줄이 아닙니다. 복잡함을 질서로 바꾸고, 생각을 다른 사람과 나눌 수 있게 만드는 작은 구조입니다. 좋은 프로그램은 많은 명령에서 시작하지 않습니다. 좋은 질문과 분명한 역할에서 시작합니다.
