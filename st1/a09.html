2. 학습 시작 멘트

생명의 진화, 별의 분류, 지식의 계보를 잇는 구조

생명과학에서는 공통 조상에서 여러 종이 갈라지는 진화 관계를 나무 모양으로 표현합니다. 천문학에서는 별을 온도와 밝기, 분광형에 따라 계층적으로 분류하고, 화학에서는 원소와 화합물의 분류 체계를 큰 범주에서 작은 범주로 나눕니다.

수학에서는 하나의 식을 연산자와 피연산자의 계층으로 표현할 수 있고, 공학에서는 설계 부품을 상위 장치와 하위 부품으로 구성합니다. 컴퓨터의 폴더와 파일도 최상위 폴더 아래 여러 하위 폴더가 이어지는 구조입니다.

트리는 단순히 나무처럼 생긴 그림이 아닙니다. 하나의 시작점에서 관계가 아래로 확장되는 계층과 분류의 언어입니다. 오늘 우리는 복잡한 대상을 부모와 자식, 깊이와 높이, 순회라는 정확한 개념으로 표현합니다.

4. 개념 및 상세 설명 · 관련 코드 · 코드별 확인 문제

개념 1. 루트, 부모, 자식, 형제, 리프

루트는 트리의 시작 정점이다. 한 정점에서 바로 아래 연결된 정점은 자식, 위쪽 정점은 부모이다. 같은 부모를 가진 정점은 형제이며, 자식이 없는 정점은 리프라고 한다.

아래 트리에서 A는 루트, B와 C는 A의 자식이자 서로 형제이다. D, E, F는 리프이다.

루트부모·자식리프
tree = { "A": ["B", "C"], "B": ["D", "E"], "C": ["F"], "D": [], "E": [], "F": [] } print(tree["A"]) print(tree["B"]) print([node for node in tree if not tree[node]])

출력: ['B','C'], ['D','E'], ['D','E','F']

코드 1 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ⑤
B와 C는 같은 부모 A를 가지며, D·E·F는 자식 리스트가 비어 있는 리프이다.
개념 2. 깊이, 높이, 서브트리

깊이는 루트에서 해당 정점까지 지나가는 간선 수이다. 루트의 깊이는 0이다. 높이는 해당 정점에서 가장 멀리 있는 리프까지의 간선 수이다.

어떤 정점과 그 아래 모든 자손으로 이루어진 부분 구조를 서브트리라고 한다.

tree = { "A": ["B", "C"], "B": ["D", "E"], "C": ["F"], "D": [], "E": [], "F": [] } def depth(node, target, d=0): if node == target: return d for child in tree[node]: result = depth(child, target, d + 1) if result != -1: return result return -1 print(depth("A", "E")) print(depth("A", "C"))

출력: 2, 1

코드 2 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ④
루트의 깊이는 0이며, 깊이는 루트에서 해당 정점까지의 거리이다.
개념 3. 인접리스트와 부모 배열로 트리 구현하기

트리는 그래프의 한 종류이므로 인접리스트로 표현할 수 있다. 무방향 간선으로 입력받으면 부모를 정하기 위해 루트에서 탐색하며 방문하지 않은 정점의 부모를 기록한다.

n = 6 edges = [(0,1), (0,2), (1,3), (1,4), (2,5)] graph = [[] for _ in range(n)] for a, b in edges: graph[a].append(b) graph[b].append(a) parent = [-1] * n parent[0] = 0 stack = [0] while stack: v = stack.pop() for nxt in graph[v]: if parent[nxt] == -1: parent[nxt] = v stack.append(nxt) print(parent)

출력: [0, 0, 0, 1, 1, 2]

코드 3 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ③, ⑤
parent 배열은 각 정점의 부모 정점을 저장하며, 이미 정한 부모를 다시 바꾸지 않는다.
개념 4. 전위 순회

전위 순회는 현재 정점을 먼저 방문하고, 그 다음 왼쪽 서브트리와 오른쪽 서브트리를 방문한다. 순서는 ‘루트→왼쪽→오른쪽’이다.

계층 구조를 위에서 아래로 출력하거나 폴더 구조를 상위 폴더부터 확인할 때 유용하다.

tree = { "A": ["B", "C"], "B": ["D", "E"], "C": ["F", "G"], "D": [], "E": [], "F": [], "G": [] } def preorder(node): print(node, end=" ") for child in tree[node]: preorder(child) preorder("A")

출력: A B D E C F G

코드 4 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ③, ④
전위 순회는 루트를 먼저 처리하고 자식 순서대로 재귀 방문한다.
개념 5. 중위 순회와 후위 순회

이진 트리에서 중위 순회는 ‘왼쪽→루트→오른쪽’, 후위 순회는 ‘왼쪽→오른쪽→루트’ 순서이다.

중위 순회는 이진 탐색 트리의 값을 정렬된 순서로 읽는 데 활용할 수 있고, 후위 순회는 자식 처리를 끝낸 뒤 부모를 처리해야 하는 계산과 삭제에 적합하다.

left = {"A":"B", "B":"D", "C":"F"} right = {"A":"C", "B":"E", "C":"G"} def inorder(node): if node in left: inorder(left[node]) print(node, end=" ") if node in right: inorder(right[node]) def postorder(node): if node in left: postorder(left[node]) if node in right: postorder(right[node]) print(node, end=" ") inorder("A") print() postorder("A")

출력:
D B E A F C G
D E B F G C A

코드 5 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ①, ②, ⑤
후위 순회는 루트를 마지막에 처리하며, 중위 순회와 방문 순서가 다르다.
개념 6. 트리의 높이와 리프 수 구하기

트리의 높이는 루트에서 가장 깊은 리프까지의 간선 수로 볼 수 있다. 리프 수와 높이는 계층 구조의 규모와 형태를 이해하는 데 도움이 된다.

아래 함수는 각 서브트리의 높이를 구해 가장 큰 값에 1을 더한다.

tree = { "A": ["B", "C"], "B": ["D", "E"], "C": ["F"], "D": [], "E": [], "F": [] } def height(node): if not tree[node]: return 0 return 1 + max(height(child) for child in tree[node]) def leaf_count(node): if not tree[node]: return 1 return sum(leaf_count(child) for child in tree[node]) print(height("A")) print(leaf_count("A"))

출력: 2, 3

코드 6 확인 문제: 옳은 것을 모두 고르시오. (3개)

정답: ②, ④, ⑤
가장 긴 경로는 A-B-D 또는 A-B-E로 간선 2개이며, 리프는 D·E·F이다.
목표지향 통합 과제
학교 조직도 또는 과학 분류 체계를 트리로 모델링한다. 루트·부모·자식·리프를 표시하고, 인접리스트 또는 자식 리스트로 구현한다. 전위 순회로 전체 구조를 출력하고 트리의 높이와 리프 수를 계산한다.

5. 학습 마무리 멘트

뿌리에서 가지로, 가지에서 다시 전체로

한 그루의 나무는 뿌리에서 시작하지만, 가지마다 서로 다른 방향으로 자랍니다. 문학의 한 주제도 여러 인물과 사건으로 뻗어 나가고, 음악의 한 동기도 다양한 변주를 만들며 작품 전체를 이룹니다.

트리는 위에서 아래로 내려다보면 분류와 확장의 구조이고, 아래에서 위로 바라보면 작은 부분들이 모여 하나의 전체가 되는 구조입니다. 전위·중위·후위 순회는 같은 대상을 서로 다른 관점에서 읽는 방법입니다.

좋은 탐구는 하나의 뿌리에서 시작해 여러 가지 가능성을 살피고, 다시 전체의 의미로 돌아옵니다.
