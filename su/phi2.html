print("오차 =", abs(math.pi - pi_estimate))

Buffon의 바늘 실험으로 π 추정

예제 코드
import random
import math

trials = 100000
crossings = 0
needle_length = 1.0
line_gap = 1.0

for _ in range(trials):
    distance = random.uniform(0, line_gap / 2)
    angle = random.uniform(0, math.pi / 2)

    if distance <= (needle_length / 2) * math.sin(angle):
        crossings += 1

pi_estimate = (
    2 * needle_length * trials
    / (line_gap * crossings)
)

print("교차 횟수 =", crossings)
print("π 추정값 =", pi_estimate)
위 Buffon의 바늘 시뮬레이션에 대한 설명으로 옳은 것을 모두 고르시오. 옳은 것 3개를 선택하세요.
