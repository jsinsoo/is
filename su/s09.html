2. 문제 분석

문제의 원인

  • 수업 중 환기 여부를 체계적으로 판단하기 어려움
  • 센서 자료에 결측값이나 비정상값이 포함될 수 있음
  • 숫자 자료만으로는 학생과 교사가 상태를 즉시 판단하기 어려움

기대 효과

  • 공기질 변화의 시간대별 특징 확인
  • 자료에 근거한 환기 시점 안내
  • 결측값과 비정상값 처리 경험
  • 데이터 분석 결과를 실제 문제 해결에 활용

9. 정답 포함 전체 코드

"""
교실 공기질 알림 프로젝트 예시 산출물
- 외부 파일 없이 실행 가능한 가상 자료 사용
- 결측값·비정상값 처리
- 상태 분류 및 환기 권고
- CSV 저장과 그래프 생성
"""

from pathlib import Path
import platform

import pandas as pd
import matplotlib.pyplot as plt

# --------------------------------------------------
# Matplotlib 한글 글꼴 설정
# --------------------------------------------------
if platform.system() == "Windows":
    plt.rcParams["font.family"] = "Malgun Gothic"
elif platform.system() == "Darwin":
    plt.rcParams["font.family"] = "AppleGothic"
else:
    # Linux·Google Colab에서 나눔고딕이 설치된 경우 사용
    plt.rcParams["font.family"] = "NanumGothic"

# 한글 글꼴에서 음수 기호가 네모로 표시되는 현상 방지
plt.rcParams["axes.unicode_minus"] = False

OUTPUT_DIR = Path("air_quality_output")
OUTPUT_DIR.mkdir(exist_ok=True)

# 1. 가상 측정 자료
data = {
    "time": [
        "09:00", "09:20", "09:40", "10:00",
        "10:20", "10:40", "11:00", "11:20"
    ],
    "co2_ppm": [620, 780, None, 1120, 1450, 5200, 980, 1350],
    "temperature_c": [22.1, 22.5, 22.8, 23.0, None, 23.7, 23.8, 24.0],
    "humidity_pct": [42, 43, 44, 45, 46, 47, -5, 49],
}

df = pd.DataFrame(data)

# 2. 전처리
df["co2_ppm"] = pd.to_numeric(
    df["co2_ppm"],
    errors="coerce"
)
df["temperature_c"] = pd.to_numeric(
    df["temperature_c"],
    errors="coerce"
)
df["humidity_pct"] = pd.to_numeric(
    df["humidity_pct"],
    errors="coerce"
)

# 물리적으로 비정상적인 범위를 결측값으로 변환
df.loc[
    ~df["co2_ppm"].between(350, 5000),
    "co2_ppm"
] = pd.NA

df.loc[
    ~df["temperature_c"].between(0, 45),
    "temperature_c"
] = pd.NA

df.loc[
    ~df["humidity_pct"].between(0, 100),
    "humidity_pct"
] = pd.NA

# 선형 보간 후 앞·뒤 결측값 보완
numeric_columns = [
    "co2_ppm",
    "temperature_c",
    "humidity_pct"
]

df[numeric_columns] = (
    df[numeric_columns]
    .interpolate(limit_direction="both")
)

# 3. 상태 분류
def classify_co2(value: float) -> str:
    """이산화탄소 농도에 따라 상태를 분류한다."""
    if value < 800:
        return "좋음"
    if value < 1000:
        return "보통"
    if value < 1500:
        return "환기 권고"
    return "즉시 환기"


def ventilation_message(status: str) -> str:
    """상태에 맞는 환기 안내 문장을 반환한다."""
    messages = {
        "좋음": "현재 상태를 유지합니다.",
        "보통": "10분 뒤 다시 확인합니다.",
        "환기 권고": "창문을 열어 5~10분 환기합니다.",
        "즉시 환기": "즉시 환기하고 인원을 분산합니다.",
    }
    return messages[status]


df["status"] = df["co2_ppm"].apply(classify_co2)
df["recommendation"] = df["status"].apply(
    ventilation_message
)

# 4. 결과 저장
csv_path = OUTPUT_DIR / "air_quality_result.csv"

df.to_csv(
    csv_path,
    index=False,
    encoding="utf-8-sig"
)

# 5. 시각화
plt.figure(figsize=(10, 5))
plt.plot(
    df["time"],
    df["co2_ppm"],
    marker="o"
)
plt.axhline(
    1000,
    linestyle="--",
    label="환기 권고 기준"
)
plt.axhline(
    1500,
    linestyle="--",
    label="즉시 환기 기준"
)
plt.xlabel("측정 시각")
plt.ylabel("CO₂ 농도(ppm)")
plt.title("교실 이산화탄소 농도 변화")
plt.xticks(rotation=45)
plt.legend()
plt.tight_layout()

graph_path = OUTPUT_DIR / "co2_trend.png"

plt.savefig(
    graph_path,
    dpi=150
)
plt.close()

# 6. 요약 보고
print(df.to_string(index=False))
print(f"\nCSV 산출물: {csv_path}")
print(f"그래프 산출물: {graph_path}")

10. 예상 실행 결과와 산출 파일

실행 결과 요약

1. 09:40의 이산화탄소 결측값은 앞뒤 값을 이용해 보간된다.
2. 10:40의 5200ppm은 비정상 범위로 판단되어 결측값으로 바뀐 뒤 보간된다.

5. 각 시각별로 좋음·보통·환기 권고·즉시 환기 상태가 부여된다.

12. 예시 정답

문항 1 정답
수업 중 공기질 악화를 즉시 파악하기 어려운 문제를 해결하며, 주요 사용자는 학생, 교사, 교실 관리자이다.
문항 2 정답
결측값은 측정되지 않은 값이고 비정상값은 측정되었지만 물리적으로 타당하지 않은 값이다. 두 경우를 그대로 사용하면 분석 결과가 왜곡될 수 있으므로 기준에 따라 결측값으로 변환하고 보완해야 한다.
문항 3 정답
측정 시각·이산화탄소·온도·습도를 입력하고, 자료형 변환과 범위 검사, 결측값 보간, 상태 분류, 환기 메시지 생성을 수행한 뒤 표·CSV·그래프로 출력한다.
문항 4 정답
필수 기능은 자료 입력, 전처리, 상태 분류, 환기 권고, CSV 저장, 그래프 생성이다. 선택 기능은 실시간 센서 연결, 자동 알림, 웹 대시보드, 교실별 비교 기능이다.
문항 5 정답
한계는 가상 자료를 사용한다는 점과 분류 기준이 교육용 예시라는 점이다. 개선 방안은 실제 센서 자료 연동, 공인 기준 적용, 여러 교실 비교, 실시간 알림과 웹 대시보드 구축 등이 있다.

14. 윤리적 고려와 한계

윤리적 고려

  • 개인 이름이나 좌석 위치를 수집하지 않는다.
  • 측정 자료의 출처와 처리 기준을 기록한다.
  • 센서 오류 가능성을 사용자에게 알린다.

프로젝트 한계

  • 가상 자료이므로 실제 교실 환경을 완전히 반영하지 못한다.
  • 환기 기준은 교육용 예시이므로 실제 적용 전 검증이 필요하다.
  • 센서 위치와 정확도에 따라 측정 결과가 달라질 수 있다.
