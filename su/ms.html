인접행렬의 n제곱을 반복해서 계산하기

0을 입력할 때까지 반복하여 n을 입력받고, 인접행렬의 n제곱을 계산하는 과정을 코드와 그래프 의미까지 단계적으로 설명합니다.

1. 전체 코드

matrix = [
    [0, 1, 1],
    [1, 0, 1],
    [1, 1, 0]
]

size = len(matrix)

def multiply(a, b):
    result = [[0] * size for _ in range(size)]

    for i in range(size):
        for j in range(size):
            for k in range(size):
                result[i][j] += a[i][k] * b[k][j]

    return result

while True:
    n = int(input("양의 정수 n 입력(종료: 0) : "))

    if n == 0:
        print("프로그램을 종료합니다.")
        break

    if n < 0:
        print("1 이상의 정수를 입력하세요.\n")
        continue

    power = [row[:] for row in matrix]

    for _ in range(n - 1):
        power = multiply(power, matrix)

    print(f"\nmatrix의 {n}제곱")

    for row in power:
        print(row)

    print()

2. 인접행렬

matrix는 정점 0, 1, 2가 서로 연결된 무방향 그래프의 인접행렬입니다.

        0
       ／ ＼
       1──2
행의미
[0,1,1]정점 0은 1, 2와 연결
[1,0,1]정점 1은 0, 2와 연결
[1,1,0]정점 2는 0, 1과 연결

3. 행렬 크기

size = len(matrix)

행의 개수가 3이므로 size = 3입니다. 숫자 3을 직접 쓰지 않아 다른 크기의 정사각행렬에도 재사용할 수 있습니다.

4. multiply(a, b) 함수

def multiply(a, b):
    result = [[0] * size for _ in range(size)]

    for i in range(size):
        for j in range(size):
            for k in range(size):
                result[i][j] += a[i][k] * b[k][j]

    return result
변수역할
i결과 행렬의 행 번호, 그래프에서는 출발 정점
j결과 행렬의 열 번호, 그래프에서는 도착 정점
k중간 위치 또는 중간 정점

핵심 식은 result[i][j] += a[i][k] * b[k][j]입니다. 한 행과 한 열의 곱을 누적하여 행렬 곱셈을 수행합니다.

5. 0을 입력할 때까지 반복

while True:

조건이 항상 참이므로 계속 반복합니다. 종료는 내부의 break가 담당합니다.

0 입력

if n == 0:
    print("프로그램을 종료합니다.")
    break

break가 while 반복문을 즉시 끝냅니다.

음수 입력

if n < 0:
    print("1 이상의 정수를 입력하세요.")
    continue

continue는 아래 계산을 건너뛰고 다시 n을 입력받게 합니다.

6. 원래 행렬 복사

power = [row[:] for row in matrix]

power를 처음에는 matrix¹로 설정합니다. 각 행을 새 리스트로 복사하여 원래 행렬과 분리합니다.

주의: 이것은 2차원 숫자 리스트에서 충분한 행 단위 복사입니다. 일반적인 중첩 객체 전체를 재귀적으로 복사하는 완전한 deep copy와는 다릅니다.

7. n제곱 계산

for _ in range(n - 1):
    power = multiply(power, matrix)
입력 n추가 곱셈 횟수결과
10회matrix¹
21회matrix²
32회matrix³
43회matrix⁴
처음부터 power가 matrix¹이므로 n제곱을 만들려면 matrix를 추가로 n-1번 곱하면 됩니다.

9. 그래프에서 matrixⁿ의 의미

행렬의미
A길이가 1인 이동 관계
A²길이가 정확히 2인 보행 수
A³길이가 정확히 3인 보행 수
Aⁿ길이가 정확히 n인 보행 수

Aⁿ[i][j]는 정점 i에서 정점 j까지 간선을 정확히 n번 사용하는 보행(walk)의 수를 나타냅니다.

같은 정점이나 간선을 다시 사용할 수 있으므로 엄밀히는 단순 경로(path)가 아니라 보행(walk)의 수입니다.

10. 시간 복잡도

행렬 곱셈 1회는 3중 반복문이므로 행렬 크기를 V라 할 때 O(V³)입니다. 이를 n-1회 반복하므로 전체는 대략 O(n·V³)입니다.

학습에는 이해하기 쉬운 방식이지만, n이 매우 크면 분할 정복을 이용한 빠른 거듭제곱으로 개선할 수 있습니다.
