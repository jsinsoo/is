BFS·DFS 심화 상세 설명

그래프와 트리의 표현부터 큐·스택·재귀 호출, 방문 배열, 탐색 순서, 최단 거리, 경로 복원, 연결 요소, 사이클 탐지, 시간 복잡도까지 단계적으로 학습합니다.
그래프 표현 BFS DFS 방문 배열 최단 경로 연결 요소 사이클 탐지 상세 코드 해설
개요 그래프 표현 BFS DFS 비교 경로 복원 연결 요소 사이클 탐지 오류 분석 확인 문제

1. BFS와 DFS의 핵심 개요

BFS: 너비 우선 탐색
시작 정점에서 가까운 정점부터 층별로 탐색합니다. 큐의 선입선출 구조를 사용합니다.
DFS: 깊이 우선 탐색
한 경로를 가능한 깊게 탐색한 뒤 더 이상 갈 수 없으면 되돌아옵니다. 재귀 호출 또는 스택을 사용합니다.
공통 핵심
그래프에서는 이미 방문한 정점을 다시 방문하지 않도록 방문 배열 또는 집합을 사용해야 합니다.
그래프 예시 0 / \ 1 2 | | 3 4 인접리스트 0: [1, 2] 1: [0, 3] 2: [0, 4] 3: [1] 4: [2]
구분BFSDFS
탐색 원리가까운 정점부터 층별 탐색한 경로를 끝까지 깊게 탐색
주요 자료구조큐스택 또는 재귀 호출
대표 활용비가중 최단 거리, 최소 이동 횟수연결 요소, 사이클, 경로 존재 여부, 백트래킹

2. 그래프의 표현

2-1. 인접리스트

graph = [ [1, 2], # 정점 0의 이웃 [0, 3], # 정점 1의 이웃 [0, 4], # 정점 2의 이웃 [1], # 정점 3의 이웃 [2] # 정점 4의 이웃 ]
인접리스트는 각 정점마다 실제로 연결된 이웃만 저장합니다. 간선 수가 정점 수보다 훨씬 적은 희소 그래프에서 공간 효율이 좋습니다.

2-2. 인접행렬

matrix = [ [0, 1, 1, 0, 0], [1, 0, 0, 1, 0], [1, 0, 0, 0, 1], [0, 1, 0, 0, 0], [0, 0, 1, 0, 0] ]
인접행렬은 두 정점의 직접 연결 여부를 빠르게 확인할 수 있지만, 정점 수가 V이면 V×V 공간이 필요합니다.
표현장점단점
인접리스트실제 간선만 저장, 이웃 순회 효율적두 정점의 직접 연결 확인은 이웃 검색 필요
인접행렬연결 여부를 바로 확인 가능정점이 많으면 공간 사용량 큼

3. BFS 상세 설명

3-1. BFS 실행 원리

  1. 시작 정점을 큐에 넣습니다.
  2. 시작 정점을 방문했다고 표시합니다.
  3. 큐의 앞에서 정점을 하나 꺼냅니다.
  4. 꺼낸 정점의 이웃 중 아직 방문하지 않은 정점을 큐에 넣습니다.
  5. 큐가 빌 때까지 반복합니다.
방문 표시는 큐에서 꺼낼 때가 아니라 큐에 넣을 때 하는 것이 안전합니다. 그래야 같은 정점이 여러 번 큐에 들어가는 것을 방지할 수 있습니다.

3-2. 기본 BFS 코드

from collections import deque graph = [ [1, 2], [0, 3], [0, 4], [1], [2] ] def bfs(start): visited = [False] * len(graph) queue = deque([start]) visited[start] = True order = [] while queue: current = queue.popleft() order.append(current) for nxt in graph[current]: if not visited[nxt]: visited[nxt] = True queue.append(nxt) return order print(bfs(0))

3-3. 코드 상세 설명

코드설명
deque([start])시작 정점을 큐에 넣습니다.
visited[start] = True시작 정점의 중복 삽입을 막습니다.
popleft()큐의 앞쪽 정점을 꺼냅니다.
for nxt in graph[current]현재 정점의 모든 이웃을 확인합니다.
queue.append(nxt)방문하지 않은 이웃을 큐 뒤에 넣습니다.

3-4. BFS 탐색 순서

초기 상태 queue = [0] 0 처리 queue = [1, 2] 1 처리 queue = [2, 3] 2 처리 queue = [3, 4] 3 처리 queue = [4] 4 처리 queue = [] 탐색 순서: 0 → 1 → 2 → 3 → 4

4. DFS 상세 설명

4-1. 재귀 DFS

graph = [ [1, 2], [0, 3], [0, 4], [1], [2] ] def dfs(current, visited, order): visited[current] = True order.append(current) for nxt in graph[current]: if not visited[nxt]: dfs(nxt, visited, order) visited = [False] * len(graph) order = [] dfs(0, visited, order) print(order)
재귀 DFS는 함수 호출 스택을 사용합니다. 현재 정점에서 방문하지 않은 이웃을 만나면 새 함수 호출이 쌓이고, 더 이상 갈 곳이 없으면 호출이 종료되면서 이전 정점으로 되돌아갑니다.

4-2. 반복형 DFS

graph = [ [1, 2], [0, 3], [0, 4], [1], [2] ] def dfs_iterative(start): visited = [False] * len(graph) stack = [start] order = [] while stack: current = stack.pop() if visited[current]: continue visited[current] = True order.append(current) for nxt in reversed(graph[current]): if not visited[nxt]: stack.append(nxt) return order print(dfs_iterative(0))
반복형 DFS에서는 이웃을 스택에 넣는 순서에 따라 방문 순서가 달라질 수 있습니다. 재귀 DFS와 같은 순서를 원하면 인접리스트를 역순으로 스택에 넣는 방법을 사용할 수 있습니다.

4-3. 호출 스택의 흐름

dfs(0) ├─ dfs(1) │ └─ dfs(3) └─ dfs(2) └─ dfs(4) 탐색 순서: 0 → 1 → 3 → 2 → 4 복귀 순서: 3 → 1 → 4 → 2 → 0

5. BFS와 DFS 비교

항목BFSDFS
탐색 방식층별 확장한 경로를 깊게 진행
자료구조큐스택 또는 재귀
최단 거리비가중 그래프에서 보장일반적으로 보장하지 않음
메모리같은 층의 정점이 많으면 큐가 커질 수 있음그래프 깊이가 크면 호출 스택 또는 명시적 스택이 커질 수 있음
주요 활용최소 이동, 감염 확산, 미로 최단 거리사이클, 연결 요소, 백트래킹, 위상 구조 분석

시간 복잡도

인접리스트를 사용하면 BFS와 DFS 모두 각 정점과 각 간선을 한 번씩 확인하므로 시간 복잡도는 일반적으로 O(V+E)입니다.

6. BFS를 이용한 최단 거리와 경로 복원

from collections import deque graph = [ [1, 2], [0, 3], [0, 4], [1, 5], [2, 5], [3, 4] ] def bfs_path(start, target): distance = [-1] * len(graph) parent = [-1] * len(graph) queue = deque([start]) distance[start] = 0 while queue: current = queue.popleft() for nxt in graph[current]: if distance[nxt] == -1: distance[nxt] = distance[current] + 1 parent[nxt] = current queue.append(nxt) path = [] current = target while current != -1: path.append(current) current = parent[current] path.reverse() return distance[target], path print(bfs_path(0, 5))

핵심 원리

  1. distance[nxt]에는 시작점에서 다음 정점까지의 최소 간선 수를 저장합니다.
  2. parent[nxt]에는 다음 정점을 처음 발견한 이전 정점을 저장합니다.
  3. 목표 정점에서 부모를 따라가면 경로가 역순으로 만들어집니다.
  4. reverse()로 시작점부터 목표점 순서로 바꿉니다.

7. 연결 요소 찾기

graph = [ [1], [0, 2], [1], [4], [3], [] ] visited = [False] * len(graph) component_sizes = [] for start in range(len(graph)): if visited[start]: continue stack = [start] visited[start] = True size = 0 while stack: current = stack.pop() size += 1 for nxt in graph[current]: if not visited[nxt]: visited[nxt] = True stack.append(nxt) component_sizes.append(size) print(component_sizes)
방문하지 않은 정점에서 새 탐색을 시작할 때마다 새로운 연결 요소가 발견됩니다. 위 그래프의 연결 요소 크기는 [3, 2, 1]입니다.

8. 무방향 그래프의 사이클 탐지

graph = [ [1, 2], [0, 2], [0, 1, 3], [2] ] def has_cycle(current, parent, visited): visited[current] = True for nxt in graph[current]: if not visited[nxt]: if has_cycle(nxt, current, visited): return True elif nxt != parent: return True return False visited = [False] * len(graph) print(has_cycle(0, -1, visited))
무방향 그래프에서는 현재 정점의 부모 정점으로 돌아가는 간선은 정상적인 역방향 간선입니다. 이미 방문한 이웃이 부모가 아닐 때 사이클로 판단합니다.

9. 자주 발생하는 오류

방문 표시 시점 오류
BFS에서 큐에 넣을 때 방문 표시하지 않으면 같은 정점이 여러 번 큐에 들어갈 수 있습니다.
방문 배열 누락
무방향 그래프에서는 서로를 다시 참조하므로 무한 반복 또는 무한 재귀가 발생할 수 있습니다.
DFS 순서 혼동
스택에 이웃을 넣는 순서에 따라 실제 방문 순서가 달라집니다.
경로 복원 역순
parent를 따라가면 목표에서 시작점 방향으로 수집되므로 마지막에 뒤집어야 합니다.
