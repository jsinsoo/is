Ⅰ. 학습 및 효율성 평가 자료

학습 목표
동일한 피보나치 값을 계산하는 단순 재귀와 메모이제이션의 실행 과정을 비교하고, 실행 시간, 함수 호출 횟수, 메모리 사용량을 근거로 효율성을 평가한다.

1. 두 방식의 차이

단순 재귀

이미 계산한 피보나치 값도 다시 계산한다. 입력값이 증가할수록 중복 호출이 급격히 증가한다.

메모이제이션

한 번 계산한 값을 캐시에 저장한 뒤 같은 입력이 다시 요청되면 저장된 값을 바로 반환한다.

비교 항목단순 재귀메모이제이션
계산 결과동일동일
중복 계산매우 많음거의 없음
시간 복잡도약 O(2ⁿ)O(n)
추가 저장 공간재귀 호출 스택재귀 호출 스택과 캐시
큰 입력 처리매우 느림상대적으로 빠름

2. 효율성 평가 전체 코드

from functools import lru_cache
from time import perf_counter
import tracemalloc

# --------------------------------------------------
# 1. 함수 호출 횟수를 저장할 전역 변수
# --------------------------------------------------
simple_calls = 0
memo_calls = 0


# --------------------------------------------------
# 2. 단순 재귀 피보나치 함수
# --------------------------------------------------
def fibonacci_simple(n: int) -> int:
    """단순 재귀 방식으로 n번째 피보나치 수를 반환한다."""
    global simple_calls
    simple_calls += 1

    if not isinstance(n, int):
        raise TypeError("n은 정수여야 합니다.")
    if n < 1:
        raise ValueError("n은 1 이상의 정수여야 합니다.")
    if n in (1, 2):
        return 1

    return fibonacci_simple(n - 1) + fibonacci_simple(n - 2)


# --------------------------------------------------
# 3. 메모이제이션 피보나치 함수
# --------------------------------------------------
@lru_cache(maxsize=None)
def fibonacci_memo(n: int) -> int:
    """메모이제이션 방식으로 n번째 피보나치 수를 반환한다."""
    global memo_calls
    memo_calls += 1

    if not isinstance(n, int):
        raise TypeError("n은 정수여야 합니다.")
    if n < 1:
        raise ValueError("n은 1 이상의 정수여야 합니다.")
    if n in (1, 2):
        return 1

    return fibonacci_memo(n - 1) + fibonacci_memo(n - 2)


# --------------------------------------------------
# 4. 함수의 실행 시간과 최대 메모리 사용량 측정
# --------------------------------------------------
def measure(function, n: int):
    """함수의 결과, 실행 시간, 최대 메모리 사용량을 반환한다."""
    tracemalloc.start()

    start = perf_counter()
    result = function(n)
    elapsed = perf_counter() - start

    current_memory, peak_memory = tracemalloc.get_traced_memory()
    tracemalloc.stop()

    return result, elapsed, peak_memory


# --------------------------------------------------
# 5. 효율성 비교 실험
# --------------------------------------------------
test_values = [5, 10, 20, 30, 35]

print("=" * 92)
print("단순 재귀와 메모이제이션 효율성 비교")
print("=" * 92)
print(
    f"{'n':>3} | {'결과':>10} | "
    f"{'단순 시간(초)':>14} | {'메모 시간(초)':>14} | "
    f"{'단순 호출':>12} | {'메모 호출':>10}"
)
print("-" * 92)

for n in test_values:
    # 각 실험 전에 호출 횟수와 캐시를 초기화한다.
    simple_calls = 0
    memo_calls = 0
    fibonacci_memo.cache_clear()

    simple_result, simple_time, simple_memory = measure(
        fibonacci_simple, n
    )

    memo_result, memo_time, memo_memory = measure(
        fibonacci_memo, n
    )

    assert simple_result == memo_result

    print(
        f"{n:>3} | {simple_result:>10} | "
        f"{simple_time:>14.8f} | {memo_time:>14.8f} | "
        f"{simple_calls:>12,} | {memo_calls:>10,}"
    )

    print(
        f"    최대 메모리 사용량: "
        f"단순 재귀 {simple_memory / 1024:.2f}KB, "
        f"메모이제이션 {memo_memory / 1024:.2f}KB"
    )

print("-" * 92)
print("메모이제이션 캐시 정보:", fibonacci_memo.cache_info())


# --------------------------------------------------
# 6. 오류 입력 검사
# --------------------------------------------------
print("\n[오류 입력 검사]")

for value in [0, -1, 3.5]:
    try:
        fibonacci_simple(value)
    except (TypeError, ValueError) as error:
        print(f"입력 {value!r}: {error}")

측정 항목의미평가 방법

5. 예시 정답

문항 1 정답
두 함수는 모두 F(1)=1, F(2)=1이라는 종료 조건과 F(n)=F(n-1)+F(n-2)라는 동일한 점화식을 사용하므로 최종 계산 결과가 같다.
문항 2 정답
단순 재귀는 같은 하위 문제를 여러 경로에서 반복 호출한다. 예를 들어 F(5)를 계산할 때 F(3), F(2), F(1)이 여러 번 다시 계산되므로 입력값이 커질수록 호출 횟수가 매우 빠르게 증가한다.
문항 3 정답
단순 재귀는 중복 계산 때문에 실행 시간과 호출 횟수가 크게 증가한다. 메모이제이션은 각 피보나치 값을 한 번만 계산하고 저장된 결과를 재사용하므로 실행 시간이 짧고 호출 횟수가 n에 비례한다.
문항 4 정답
메모이제이션은 이전에 계산한 입력값과 결과를 캐시에 저장해야 하므로 추가 메모리를 사용한다. 대신 이 저장 공간을 이용하여 중복 계산을 없애고 실행 시간을 줄인다.
문항 5 정답
n=40 이상에서는 단순 재귀의 호출 횟수가 매우 많아 실행 시간이 지나치게 길어질 수 있으므로 적절하지 않다. 메모이제이션이나 반복문 방식이 더 적합하다.

6. 평가 결론

정확성: 두 방식은 동일한 점화식과 종료 조건을 사용하므로 결과가 같다.

시간 효율성: 메모이제이션이 단순 재귀보다 훨씬 우수하다.

공간 효율성: 단순 재귀는 캐시를 사용하지 않지만 호출 스택을 사용하며, 메모이제이션은 캐시 저장 공간이 추가로 필요하다.

종합 판단: 입력값이 작고 재귀 원리를 학습하는 경우에는 단순 재귀가 유용하지만, 실제 계산에서는 메모이제이션 또는 반복 방식이 더 적절하다.
