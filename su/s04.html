Ⅰ. 스택 활용 괄호 검사 학습자료

성취 목표
문제의 특성에 적합한 자료구조를 선택하고, 스택을 활용하여 괄호의 짝과 순서를 검사하는 프로그램을 작성하며, 다양한 시험 자료를 통해 정확성과 효율성을 분석한다.

1. 문제 상황

수식이나 프로그램 코드에 사용된 소괄호 (), 대괄호 [], 중괄호 {}가 올바른 순서로 열리고 닫혔는지 검사하는 프로그램을 작성한다.

올바른 예

(a+b)*[c-d]

{[()]}

{[(a+b)*(c-d)]}

올바르지 않은 예

(a+b] — 종류가 다름

((a+b) — 닫는 괄호 부족

)(a+b)( — 순서가 잘못됨

2. 스택이 적합한 이유

가장 최근에 열린 괄호가 가장 먼저 닫혀야 하므로, 마지막에 저장한 자료를 먼저 꺼내는 LIFO 구조인 스택이 적합하다.

TOP
(
[
{
최근 여는 괄호부터 확인

3. 알고리즘 설계

  1. 빈 스택을 준비한다.
  2. 문자열의 문자를 앞에서부터 하나씩 확인한다.
  3. 여는 괄호를 만나면 스택에 삽입한다.
  4. 닫는 괄호를 만나면 스택이 비어 있는지 확인한다.
  5. 스택의 맨 위 여는 괄호와 현재 닫는 괄호가 짝을 이루는지 확인한다.
  6. 짝이 맞으면 스택에서 제거하고, 맞지 않으면 False를 반환한다.
  7. 문자열 검사가 끝난 뒤 스택이 비어 있으면 True를 반환한다.

4. 수행 과제

  1. 함수 is_balanced(text)를 작성한다.
  2. 소괄호·대괄호·중괄호를 모두 처리한다.
  3. 괄호가 없는 문자열과 빈 문자열도 검사한다.
  4. 정상·오류·경계 사례를 포함한 시험 자료를 만든다.
  5. 프로그램의 시간 복잡도와 공간 복잡도를 분석한다.

6. 정답 포함 전체 코드

def is_balanced(text: str) -> bool:
    """
    문자열에 포함된 (), [], {} 괄호의 짝과 순서가 올바른지 검사한다.
    괄호가 없거나 빈 문자열인 경우 True를 반환한다.
    """
    stack: list[str] = []
    pairs = {")": "(", "]": "[", "}": "{"}
    opening = set(pairs.values())

    for ch in text:
        # 여는 괄호는 스택에 저장한다.
        if ch in opening:
            stack.append(ch)

        # 닫는 괄호를 만나면 스택의 맨 위와 짝을 확인한다.
        elif ch in pairs:
            # 스택이 비어 있으면 대응하는 여는 괄호가 없는 경우이다.
            if not stack:
                return False

            # 가장 최근의 여는 괄호가 현재 닫는 괄호와 맞지 않는 경우이다.
            if stack[-1] != pairs[ch]:
                return False

            # 짝이 맞으면 여는 괄호를 스택에서 제거한다.
            stack.pop()

    # 검사가 끝난 뒤 스택이 비어 있어야 모든 괄호의 짝이 맞는다.
    return len(stack) == 0


test_cases = {
    "A": "(a+b)*[c-d]",
    "B": "{{a+b}*[c-d]}",
    "C": "(a+b]",
    "D": "((a+b)",
    "E": "{[()]}",
    "F": "",
    "G": "abc+123",
    "H": ")(a+b)(",
    "I": "{[(a+b)*(c-d)]}",
}

print("=" * 56)
print("괄호 짝 검사 결과")
print("=" * 56)

for name, text in test_cases.items():
    result = is_balanced(text)
    state = "올바름" if result else "올바르지 않음"
    print(f"{name}. {text!r:<24} -> {result:<5} ({state})")


# 추가 시험
assert is_balanced("(a+b)*[c-d]") is True
assert is_balanced("{{a+b}*[c-d]}") is True
assert is_balanced("(a+b]") is False
assert is_balanced("((a+b)") is False
assert is_balanced("{[()]}") is True
assert is_balanced("") is True
assert is_balanced("abc+123") is True

print("\n모든 핵심 시험을 통과했습니다.")

10. 예시 정답

문항 1 정답
가장 최근에 열린 괄호가 가장 먼저 닫혀야 하므로 LIFO 방식의 스택이 적합하다. 큐는 먼저 들어온 자료를 먼저 처리하므로 중첩 괄호의 짝을 검사하기에 적합하지 않다.
문항 2 정답
여는 괄호는 스택에 삽입한다. 닫는 괄호를 만나면 스택의 맨 위 자료가 현재 닫는 괄호와 짝을 이루는지 확인하고, 짝이 맞으면 스택에서 제거한다.
문항 3 정답
스택이 비어 있다는 것은 현재 닫는 괄호에 대응하는 이전의 여는 괄호가 없다는 뜻이다. 따라서 괄호의 순서가 올바르지 않으므로 False를 반환한다.
문항 4 정답
문자열 검사가 끝났는데 스택에 여는 괄호가 남아 있다면 닫히지 않은 괄호가 있다는 뜻이다. 모든 괄호가 정확하게 닫혔을 때만 스택이 비어 있으므로 이를 최종 조건으로 확인한다.
문항 5 정답
문자열의 각 문자를 한 번씩 검사하므로 시간 복잡도는 O(n)이다. 모든 문자가 여는 괄호일 수 있으므로 최악의 경우 스택에 n개의 문자를 저장하여 공간 복잡도는 O(n)이다.

12. 종합 정리

문제 해결 원리: 최근에 열린 괄호를 가장 먼저 확인해야 하므로 스택을 사용한다.

정확성 조건: 닫는 괄호의 짝이 맞아야 하고, 검사 종료 후 스택이 비어 있어야 한다.

효율성: 문자열을 한 번 순회하므로 시간 복잡도는 O(n)이며, 최악의 공간 복잡도는 O(n)이다.

확장 가능성: 수식 검사, 프로그램 코드 문법 검사, 태그 중첩 검사 등에 활용할 수 있다.
