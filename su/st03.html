기초 3

기본 BFS 탐색

from collections import deque

graph = [[1, 2], [0, 3], [0, 4], [1], [2]]
visited = [False] * len(graph)
queue = deque([0])
visited[0] = True
order = []

while queue:
    current = queue.popleft()
    order.append(current)
    for nxt in graph[current]:
        if not visited[nxt]:
            visited[nxt] = True
            queue.append(nxt)

print(order)
알기 쉬운 설명
시작점 0에서 가까운 정점부터 0, 1, 2, 3, 4 순서로 탐색합니다.
핵심 확인

방문 표시는 큐에 넣을 때 하는 것이 중복 삽입을 막는 데 안전합니다.

기초 5

반복형 DFS 탐색

graph = [[1, 2], [0, 3], [0, 4], [1], [2]]
visited = [False] * len(graph)
stack = [0]
order = []

while stack:
    current = stack.pop()
    if visited[current]:
        continue
    visited[current] = True
    order.append(current)
    for nxt in reversed(graph[current]):
        if not visited[nxt]:
            stack.append(nxt)

print(order)
알기 쉬운 설명
재귀 호출 대신 리스트를 스택으로 사용합니다. 이웃을 역순으로 넣으면 재귀 DFS와 비슷한 순서가 됩니다.
핵심 확인

스택은 후입선출 구조입니다.

응용 1

BFS 최단 거리

from collections import deque

graph = [[1, 2], [0, 3], [0, 4], [1], [2]]
distance = [-1] * len(graph)
queue = deque([0])
distance[0] = 0

while queue:
    current = queue.popleft()
    for nxt in graph[current]:
        if distance[nxt] == -1:
            distance[nxt] = distance[current] + 1
            queue.append(nxt)

print(distance)
알기 쉬운 설명
비가중 그래프에서 처음 기록된 거리가 시작점으로부터의 최소 간선 수 거리입니다.
핵심 확인

결과는 [0, 1, 1, 2, 2]입니다.

응용 2

미로 최단 거리

from collections import deque

maze = [[1, 1, 0], [0, 1, 1], [1, 1, 1]]
distance = [[-1] * 3 for _ in range(3)]
queue = deque([(0, 0)])
distance[0][0] = 0
directions = [(1,0), (-1,0), (0,1), (0,-1)]

while queue:
    r, c = queue.popleft()
    for dr, dc in directions:
        nr, nc = r + dr, c + dc
        if 0 <= nr < 3 and 0 <= nc < 3:
            if maze[nr][nc] == 1 and distance[nr][nc] == -1:
                distance[nr][nc] = distance[r][c] + 1
                queue.append((nr, nc))

print(distance[2][2])
알기 쉬운 설명
2차원 격자도 각 칸을 정점으로 보면 그래프입니다. 상하좌우 이동을 간선으로 해석합니다.
핵심 확인

목표 칸까지의 최소 이동 횟수는 4입니다.

응용 3

DFS 연결 요소 수

graph = [[1], [0, 2], [1], [4], [3], []]
visited = [False] * len(graph)
components = 0

def dfs(start):
    visited[start] = True
    for nxt in graph[start]:
        if not visited[nxt]:
            dfs(nxt)

for vertex in range(len(graph)):
    if not visited[vertex]:
        components += 1
        dfs(vertex)

print(components)
알기 쉬운 설명
방문하지 않은 정점에서 새 DFS를 시작할 때마다 연결 요소 수를 1 증가시킵니다.
핵심 확인

연결 요소는 {0,1,2}, {3,4}, {5}의 3개입니다.

심화 예시 5개

심화 1

BFS 최단 경로 복원

from collections import deque

graph = [[1, 2], [0, 3], [0, 4], [1, 5], [2, 5], [3, 4]]
distance = [-1] * len(graph)
parent = [-1] * len(graph)
queue = deque([0])
distance[0] = 0

while queue:
    current = queue.popleft()
    for nxt in graph[current]:
        if distance[nxt] == -1:
            distance[nxt] = distance[current] + 1
            parent[nxt] = current
            queue.append(nxt)

path = []
target = 5
while target != -1:
    path.append(target)
    target = parent[target]
path.reverse()
print(path)
알기 쉬운 설명
parent 배열에는 정점을 처음 발견한 이전 정점을 저장합니다. 목표에서 부모를 따라간 뒤 뒤집으면 경로가 됩니다.
핵심 확인

한 최단 경로는 [0, 1, 3, 5]입니다.

심화 2

다중 시작점 BFS

from collections import deque

graph = [[1], [0, 2, 4], [1, 3], [2, 4], [1, 3, 5], [4]]
sources = [0, 5]
distance = [-1] * len(graph)
queue = deque(sources)

for source in sources:
    distance[source] = 0

while queue:
    current = queue.popleft()
    for nxt in graph[current]:

            distance[nxt] = distance[current] + 1
            queue.append(nxt)

print(distance)
알기 쉬운 설명
여러 시작점을 처음부터 큐에 넣으면 각 정점에서 가장 가까운 시작점까지의 거리를 구할 수 있습니다.
핵심 확인

결과는 [0, 1, 2, 2, 1, 0]입니다.

심화 3

무방향 그래프 사이클 탐지

graph = [[1, 2], [0, 2], [0, 1, 3], [2]]
visited = [False] * len(graph)

def has_cycle(current, parent):
    visited[current] = True
    for nxt in graph[current]:
        if not visited[nxt]:
            if has_cycle(nxt, current):
                return True
        elif nxt != parent:
            return True
    return False

print(has_cycle(0, -1))
알기 쉬운 설명
이미 방문한 이웃이 현재 정점의 부모가 아니라면 다른 경로로 다시 만난 것이므로 사이클입니다.
핵심 확인

0-1-2-0 사이클이 있어 True입니다.

심화 4

서브트리 크기 계산

tree = [[1, 2], [3, 4], [5], [], [], []]
subtree = [0] * len(tree)

def count_subtree(node):
    total = 1
    for child in tree[node]:
        total += count_subtree(child)
    subtree[node] = total
    return total

count_subtree(0)
print(subtree)
알기 쉬운 설명
리프에서부터 크기를 반환하고 부모가 자식들의 크기를 합합니다.

심화 5

BFS와 DFS 순서 비교

from collections import deque

graph = [[1, 2], [0, 3, 4], [0, 5], [1], [1], [2]]

def bfs(start):
    visited = [False] * len(graph)
    queue = deque([start])
    visited[start] = True
    order = []
    while queue:
        current = queue.popleft()
        order.append(current)
        for nxt in graph[current]:
            if not visited[nxt]:
                visited[nxt] = True
                queue.append(nxt)
    return order

def dfs(current, visited, order):
    visited[current] = True
    order.append(current)
    for nxt in graph[current]:
        if not visited[nxt]:
            dfs(nxt, visited, order)

dfs_order = []
dfs(0, [False] * len(graph), dfs_order)
print("BFS:", bfs(0))
print("DFS:", dfs_order)
알기 쉬운 설명
BFS는 층별로, DFS는 한 경로를 깊게 탐색합니다. 같은 그래프라도 순서가 다릅니다.
핵심 확인

BFS는 [0,1,2,3,4,5], DFS는 [0,1,3,4,2,5]입니다.

마무리 비교

BFS는 최소 이동 횟수나 단계별 확산처럼 가까운 곳부터 처리해야 할 때 적합합니다.

DFS는 연결 구조, 사이클, 서브트리처럼 한 경로를 깊게 조사해야 할 때 적합합니다.

두 알고리즘 모두 그래프에서는 방문 여부를 기록해야 무한 반복과 중복 탐색을 막을 수 있습니다.
