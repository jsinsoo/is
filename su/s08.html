Ⅰ. 동적계획법 계단 오르기 학습자료

성취 목표
중복되는 부분 문제를 찾아 상태와 점화식을 정의하고, 단순 재귀·메모이제이션· 테이블 방식으로 각각 구현한 뒤 실행 시간과 호출 횟수를 근거로 효율성을 비교한다.

1. 문제 상황

한 번에 1칸 또는 2칸씩 오를 수 있을 때, n칸 계단을 오르는 방법의 수를 구한다.

n-1칸에서 1칸 이동 + n-2칸에서 2칸 이동 = n칸 도달 방법

2. 상태와 점화식

구성 요소정의
상태dp[n]: n칸 계단을 오르는 방법의 수
초기값dp[1] = 1, dp[2] = 2
점화식dp[n] = dp[n-1] + dp[n-2]
중복 부분 문제단순 재귀에서 같은 n값을 여러 번 다시 계산함
해결 전략이미 계산한 값을 저장하여 재사용함

3. 세 가지 해결 방식

단순 재귀

점화식을 그대로 표현하지만 같은 부분 문제를 반복 계산한다.

시간 복잡도는 지수적으로 증가한다.

메모이제이션

재귀 호출 결과를 캐시에 저장하고 같은 입력에서는 저장값을 반환한다.

위에서 아래로 문제를 해결하는 방식이다.

테이블 방식

작은 상태부터 차례로 표를 채워 큰 상태의 값을 계산한다.

아래에서 위로 문제를 해결하는 방식이다.

6. 정답 포함 전체 코드

import time
from functools import lru_cache
from statistics import mean

recursive_calls = 0


def stairs_recursive(n: int) -> int:
    """단순 재귀 방식으로 n칸 계단을 오르는 방법의 수를 반환한다."""
    global recursive_calls
    recursive_calls += 1

    if not isinstance(n, int):
        raise TypeError("n은 정수여야 합니다.")
    if n < 1:
        raise ValueError("n은 1 이상이어야 합니다.")
    if n == 1:
        return 1
    if n == 2:
        return 2

    return stairs_recursive(n - 1) + stairs_recursive(n - 2)


def stairs_dp(n: int) -> int:
    """테이블 방식의 동적계획법으로 결과를 계산한다."""
    if not isinstance(n, int):
        raise TypeError("n은 정수여야 합니다.")
    if n < 1:
        raise ValueError("n은 1 이상이어야 합니다.")
    if n == 1:
        return 1

    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2

    for step in range(3, n + 1):
        dp[step] = dp[step - 1] + dp[step - 2]

    return dp[n]


@lru_cache(maxsize=None)
def stairs_memo(n: int) -> int:
    """메모이제이션 방식으로 결과를 계산한다."""
    if not isinstance(n, int):
        raise TypeError("n은 정수여야 합니다.")
    if n < 1:
        raise ValueError("n은 1 이상이어야 합니다.")
    if n == 1:
        return 1
    if n == 2:
        return 2

    return stairs_memo(n - 1) + stairs_memo(n - 2)


def stairs_optimized(n: int) -> int:
    """직전 두 값만 저장하여 공간을 O(1)로 줄인 방식."""
    if not isinstance(n, int):
        raise TypeError("n은 정수여야 합니다.")
    if n < 1:
        raise ValueError("n은 1 이상이어야 합니다.")
    if n == 1:
        return 1

    previous, current = 1, 2

    for _ in range(3, n + 1):
        previous, current = current, previous + current

    return current


def average_time(function, n: int, repeat: int = 5) -> float:
    """함수를 여러 번 실행하고 평균 실행 시간을 반환한다."""
    measured = []

    for _ in range(repeat):
        start = time.perf_counter()
        function(n)
        measured.append(time.perf_counter() - start)

    return mean(measured)


test_values = [5, 10, 20, 30]

print("=" * 112)
print("단순 재귀·메모이제이션·동적계획법 비교")
print("=" * 112)
print(
    f"{'n':>3} | {'결과':>10} | {'재귀 호출':>12} | "
    f"{'재귀 시간(초)':>14} | {'메모 시간(초)':>14} | "
    f"{'DP 시간(초)':>14} | {'결과 일치':>9}"
)
print("-" * 112)

for n in test_values:
    recursive_calls = 0
    stairs_memo.cache_clear()

    recursive_time = average_time(stairs_recursive, n, repeat=1)
    recursive_result = stairs_recursive(n)

    memo_time = average_time(stairs_memo, n, repeat=5)
    memo_result = stairs_memo(n)

    dp_time = average_time(stairs_dp, n, repeat=5)
    dp_result = stairs_dp(n)

    optimized_result = stairs_optimized(n)

    all_same = (
        recursive_result
        == memo_result
        == dp_result
        == optimized_result
    )

    print(
        f"{n:>3} | {dp_result:>10} | {recursive_calls:>12,} | "
        f"{recursive_time:>14.8f} | {memo_time:>14.8f} | "
        f"{dp_time:>14.8f} | {str(all_same):>9}"
    )

print("-" * 112)
print("메모이제이션 캐시 정보:", stairs_memo.cache_info())


print("\n[오류 입력 검사]")

for value in [0, -1, 3.5]:
    for function in (
        stairs_recursive,
        stairs_memo,
        stairs_dp,
        stairs_optimized,
    ):
        try:
            function(value)
        except (TypeError, ValueError) as error:
            print(f"{function.__name__}({value!r}) -> {error}")

10. 예시 정답

문항 1 정답
dp[n]은 n칸 계단을 오르는 방법의 수이다. 초기값은 dp[1]=1, dp[2]=2이고, 마지막 이동이 1칸 또는 2칸이므로 dp[n]=dp[n-1]+dp[n-2]이다.
문항 2 정답
하나의 재귀 호출이 n-1과 n-2를 다시 호출하고, 각 호출도 같은 구조로 더 작은 값을 호출한다. 따라서 같은 n값이 여러 재귀 경로에서 반복해서 계산된다.
문항 3 정답
메모이제이션은 한 번 계산한 입력과 결과를 캐시에 저장한다. 같은 입력이 다시 요청되면 재귀 계산을 반복하지 않고 저장된 결과를 바로 반환한다.
문항 4 정답
두 방식 모두 각 부분 문제를 한 번만 계산하고 결과를 저장한다는 공통점이 있다. 메모이제이션은 재귀 호출을 이용하여 필요한 상태부터 계산하고, 테이블 방식은 작은 상태부터 반복문으로 차례대로 계산한다.
문항 5 정답
단순 재귀의 시간 복잡도는 약 O(2ⁿ), 메모이제이션과 테이블 방식은 O(n)이다. 세 방식 모두 구현에 따라 O(n)의 공간을 사용할 수 있다. 큰 입력에서는 메모이제이션이나 테이블 방식이 적합하며, 재귀 깊이 제한을 피하려면 테이블 방식 또는 공간 최적화 반복 방식이 더 안정적이다.

12. 종합 정리

단순 재귀: 점화식을 직접 표현하지만 중복 계산이 많아 큰 입력에 비효율적이다.

메모이제이션: 재귀 결과를 저장하여 각 상태를 한 번만 계산한다.

테이블 방식: 작은 상태부터 반복적으로 계산하여 재귀 깊이 제한 없이 안정적으로 처리한다.

공간 최적화: 직전 두 상태만 필요한 문제에서는 전체 테이블 대신 두 변수만 사용하여 공간을 O(1)로 줄일 수 있다.
