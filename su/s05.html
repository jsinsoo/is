Ⅰ. 상태 공간 완전 탐색 BFS 학습자료

성취 목표
문제를 상태 공간으로 구조화하고, 초기 상태에서 가능한 상태를 빠짐없이 탐색하여 목표 상태에 도달하는 알고리즘을 설계하며, 탐색 결과의 정확성과 효율성을 분석한다.

1. 문제 상황

2. 상태 공간 구조화

구성 요소정의
상태현재 위치를 나타내는 좌표 (행, 열)
초기 상태(0, 0)
목표 상태(3, 3)
전이 규칙현재 위치에서 상·하·좌·우의 인접 위치로 이동
제약 조건미로 범위 안에 있고, 벽이 아니며, 아직 방문하지 않은 위치
목표 검사큐에서 꺼낸 현재 위치가 목표점과 같은지 확인

3. 너비 우선 탐색 원리

큐 사용

먼저 발견한 상태를 먼저 탐색하는 FIFO 구조의 큐를 사용한다. 시작점에서 가까운 상태부터 차례로 탐색한다.

방문 집합 사용

이미 방문한 위치를 다시 큐에 넣지 않도록 visited 집합에 저장한다. 중복 탐색과 무한 반복을 방지한다.

4. 수행 과제

  1. 상태, 초기 상태, 목표 상태, 전이 규칙, 제약 조건을 정의한다.
  2. 너비 우선 탐색 알고리즘을 의사코드로 표현한다.
  3. 최단 경로를 반환하는 find_path_bfs() 함수를 작성한다.
  4. 찾은 경로를 문자로 시각화한다.
  5. 정상 경로, 시작점과 목표점이 같은 경우, 경로가 없는 경우를 시험한다.
  6. 시간 복잡도와 공간 복잡도를 분석한다.

6. 정답 포함 전체 코드

from collections import deque
from typing import Optional

# 0: 이동 가능한 칸, 1: 벽
maze = [
    [0, 0, 1, 0],
    [1, 0, 1, 0],
    [0, 0, 0, 0],
    [0, 1, 1, 0],
]

start = (0, 0)
goal = (3, 3)

# 상, 하, 좌, 우 이동
DIRECTIONS = [
    (-1, 0),
    (1, 0),
    (0, -1),
    (0, 1),
]


def find_path_bfs(
    grid: list[list[int]],
    start_point: tuple[int, int],
    goal_point: tuple[int, int],
) -> Optional[list[tuple[int, int]]]:
    """
    너비 우선 탐색으로 시작점에서 목표점까지의 최단 경로를 찾는다.
    경로가 없으면 None을 반환한다.
    """
    if not grid or not grid[0]:
        raise ValueError("미로가 비어 있습니다.")

    rows = len(grid)
    cols = len(grid[0])

    # 모든 행의 길이가 같은지 확인한다.
    if any(len(row) != cols for row in grid):
        raise ValueError("미로의 모든 행 길이는 같아야 합니다.")

    def is_valid_point(point: tuple[int, int]) -> bool:
        row, col = point
        return (
            0 <= row < rows
            and 0 <= col < cols
            and grid[row][col] == 0
        )

    if not is_valid_point(start_point):
        raise ValueError("시작점이 범위를 벗어나거나 벽입니다.")

    if not is_valid_point(goal_point):
        raise ValueError("목표점이 범위를 벗어나거나 벽입니다.")

    # 큐에는 (현재 위치, 현재 위치까지의 경로)를 저장한다.
    queue = deque([(start_point, [start_point])])

    # 이미 방문한 위치를 다시 탐색하지 않도록 집합에 저장한다.
    visited = {start_point}

    while queue:
        (row, col), path = queue.popleft()

        # 목표 상태에 도달한 경우 현재 경로를 반환한다.
        if (row, col) == goal_point:
            return path

        # 현재 상태에서 가능한 다음 상태를 생성한다.
        for dr, dc in DIRECTIONS:
            nr = row + dr
            nc = col + dc
            next_point = (nr, nc)

            inside = 0 <= nr < rows and 0 <= nc < cols
            movable = inside and grid[nr][nc] == 0
            unvisited = next_point not in visited

            if movable and unvisited:
                visited.add(next_point)
                queue.append((next_point, path + [next_point]))

    return None


def draw_path(
    grid: list[list[int]],
    path: list[tuple[int, int]],
    start_point: tuple[int, int],
    goal_point: tuple[int, int],
) -> None:
    """찾은 경로를 문자로 시각화한다."""
    path_set = set(path)

    for row_index, row in enumerate(grid):
        line = []

        for col_index, value in enumerate(row):
            point = (row_index, col_index)

            if point == start_point:
                line.append("S")
            elif point == goal_point:
                line.append("G")
            elif point in path_set:
                line.append("*")
            elif value == 1:
                line.append("#")
            else:
                line.append(".")

        print(" ".join(line))


def test_maze(
    grid: list[list[int]],
    start_point: tuple[int, int],
    goal_point: tuple[int, int],
) -> None:
    """미로 탐색 결과를 출력한다."""
    path = find_path_bfs(grid, start_point, goal_point)

    if path is None:
        print("경로가 없습니다.")
        return

    print("최단 경로:", path)
    print("이동 횟수:", len(path) - 1)
    draw_path(grid, path, start_point, goal_point)


print("=" * 56)
print("너비 우선 탐색을 이용한 미로 최단 경로")
print("=" * 56)

test_maze(maze, start, goal)

    [0, 1, 0],

8. 알고리즘 의사코드

큐에 (시작점, [시작점])을 삽입한다.
시작점을 방문 집합에 저장한다.

큐가 비어 있지 않은 동안 반복한다.
    현재 위치와 현재 경로를 큐에서 꺼낸다.

    현재 위치가 목표점이면
        현재 경로를 반환한다.

    상·하·좌·우의 다음 위치를 만든다.

    다음 위치가
        미로 범위 안이고
        벽이 아니며
        아직 방문하지 않았다면

        방문 집합에 추가한다.
        다음 위치와 확장된 경로를 큐에 삽입한다.

모든 상태를 탐색해도 목표에 도달하지 못하면
    None을 반환한다.

10. 예시 정답

문항 1 정답
상태는 현재 위치의 좌표이다. 초기 상태는 (0,0), 목표 상태는 (3,3)이다. 전이 규칙은 현재 위치에서 상·하·좌·우의 이동 가능한 인접 칸으로 이동하는 것이다.
문항 2 정답
큐는 먼저 발견한 상태를 먼저 처리하는 FIFO 구조이다. 너비 우선 탐색은 시작점에서 가까운 상태부터 탐색해야 하므로 큐가 적합하다.
문항 3 정답
방문한 위치를 다시 탐색하면 같은 위치가 여러 번 큐에 들어가 탐색량이 증가한다. 서로 연결된 위치를 계속 왕복하면 반복이 끝나지 않을 수도 있다.
문항 4 정답
모든 이동의 비용이 1로 같고, 너비 우선 탐색은 이동 횟수가 적은 상태부터 차례로 탐색한다. 따라서 목표점이 처음 발견될 때의 경로가 최소 이동 횟수의 경로가 된다.
문항 5 정답
각 칸을 최대 한 번 방문하고 각 칸에서 네 방향을 확인하므로 시간 복잡도는 O(RC)이다. 큐, 방문 집합, 경로 정보에 최대 RC개의 위치가 저장될 수 있으므로 공간 복잡도도 O(RC)이다.

12. 종합 정리

상태 공간: 미로의 이동 가능한 각 위치가 하나의 상태가 된다.

완전 탐색: 큐에 발견한 상태를 저장하여 도달 가능한 상태를 빠짐없이 탐색한다.

최단 경로: 모든 이동 비용이 같을 때 너비 우선 탐색은 최소 이동 횟수의 경로를 찾는다.

효율성: 방문 집합을 사용하면 각 칸을 최대 한 번 탐색하여 중복을 줄일 수 있다.
