BFS와 DFS로 같은 결과를 만드는 기하학적 도형 20선

Python Turtle · 큐 BFS · 스택 DFS · 최종 결과는 같고 실행 순서는 다르게
핵심: BFS는 queue의 FIFO 순서로 같은 깊이를 먼저 처리하고, DFS는 stack의 LIFO 순서로 한 갈래를 먼저 깊게 처리합니다. 아래 예제들은 모두 같은 draw(node)와 children(node) 규칙을 공유하므로 방문 순서만 다르고 최종 도형은 동일합니다.

01

이진 가지 나무

좌우 두 가지로 분기하는 기본 프랙탈 트리.

실행 차이: BFS는 같은 깊이의 노드를 먼저 처리하고, DFS는 한 갈래를 깊게 처리합니다. children(node)가 만드는 자식 좌표가 동일하므로 최종 도형은 같습니다.
BFSqueue / deque
import turtle
from collections import deque

t=turtle.Turtle()
t.speed(0)
t.hideturtle()

import math

def draw(node):
    x,y,a,L,d=node
    r=math.radians(a)
    x2=x+L*math.cos(r); y2=y+L*math.sin(r)
    t.penup(); t.goto(x,y); t.pendown(); t.goto(x2,y2)

def children(node):
    x,y,a,L,d=node
    if d==0: return []
    r=math.radians(a)
    x2=x+L*math.cos(r); y2=y+L*math.sin(r)
    return [(x2,y2,a+25,L*.72,d-1),(x2,y2,a-25,L*.72,d-1)]

q=deque([(0,-300,90,120,7)])

while q:
    node=q.popleft()
    draw(node)
    for child in children(node):
        q.append(child)

turtle.done()

3:4:5 피타고라스 나무

부모 정사각형 위에 3:4:5 비율의 두 자식 정사각형을 생성.

실행 차이: BFS는 같은 깊이의 노드를 먼저 처리하고, DFS는 한 갈래를 깊게 처리합니다. children(node)가 만드는 자식 좌표가 동일하므로 최종 도형은 같습니다.
BFSqueue / deque
import turtle
from collections import deque

t=turtle.Turtle()
t.speed(0)
t.hideturtle()

def square(A,B):
    x1,y1=A; x2,y2=B
    dx,dy=x2-x1,y2-y1
    C=(x2-dy,y2+dx); D=(x1-dy,y1+dx)
    t.penup(); t.goto(A); t.pendown()
    t.goto(B); t.goto(C); t.goto(D); t.goto(A)
    return D,C

def draw(node):
    A,B,d=node
    square(A,B)

def children(node):
    A,B,d=node
    if d==0: return []
    x1,y1=A; x2,y2=B
    dx,dy=x2-x1,y2-y1
    C=(x2-dy,y2+dx); D=(x1-dy,y1+dx)
    L,R=D,C
    dx,dy=R[0]-L[0],R[1]-L[1]
    P=(L[0]+16/25*dx-12/25*dy,
       L[1]+16/25*dy+12/25*dx)
    return [(L,P,d-1),(P,R,d-1)]

q=deque([((-70,-330),(70,-330),9)])

while q:
    node=q.popleft()
    draw(node)
    for child in children(node):
        q.append(child)

turtle.done()

정사각형의 중심과 네 모서리에 작은 정사각형을 배치.

실행 차이: BFS는 같은 깊이의 노드를 먼저 처리하고, DFS는 한 갈래를 깊게 처리합니다. children(node)가 만드는 자식 좌표가 동일하므로 최종 도형은 같습니다.

import turtle
from collections import deque

t=turtle.Turtle()
t.speed(0)

def draw(node):
    cx,cy,s,d=node; h=s/2
    t.penup(); t.goto(cx-h,cy-h); t.setheading(0); t.pendown()
    for _ in range(4): t.forward(s); t.left(90)

시에르핀스키 카펫

3×3 분할에서 가운데를 제외한 8개 칸을 반복.

실행 차이: BFS는 같은 깊이의 노드를 먼저 처리하고, DFS는 한 갈래를 깊게 처리합니다. children(node)가 만드는 자식 좌표가 동일하므로 최종 도형은 같습니다.
BFSqueue / deque
import turtle
from collections import deque

t=turtle.Turtle()
t.speed(0)
t.hideturtle()

def draw(node):
    x,y,s,d=node
    t.penup(); t.goto(x,y); t.setheading(0); t.pendown()
    for _ in range(4): t.forward(s); t.left(90)

def children(node):
    x,y,s,d=node
    if d==0:return []
    ns=s/3; out=[]
    for r in range(3):
        for c in range(3):
            if (r,c)!=(1,1): out.append((x+c*ns,y+r*ns,ns,d-1))
    return out

q=deque([(-270,-270,540,3)])

while q:
    node=q.popleft()
    draw(node)
    for child in children(node):
        q.append(child)

turtle.done()

육각 방사형 가지

한 점에서 60° 간격 여섯 방향으로 분기.

실행 차이: BFS는 같은 깊이의 노드를 먼저 처리하고, DFS는 한 갈래를 깊게 처리합니다. children(node)가 만드는 자식 좌표가 동일하므로 최종 도형은 같습니다.
BFSqueue / deque
import turtle
from collections import deque

t=turtle.Turtle()
t.speed(0)
t.hideturtle()

import math

def draw(node):
    x,y,L,d=node
    if d<0:return
    for a in range(0,360,60):
        r=math.radians(a); x2=x+L*math.cos(r); y2=y+L*math.sin(r)
        t.penup(); t.goto(x,y); t.pendown(); t.goto(x2,y2)

def children(node):
    x,y,L,d=node

def children(node):
    x,y,a,L,d=node
    if d==0:return []
    x2,y2=endpoint(x,y,a,L)
    return [(x2,y2,a+25,L*.55,d-1),(x2,y2,a-25,L*.55,d-1)]

stack=list([(0,0,a,150,5) for a in range(0,360,60)])

while stack:
    node=stack.pop()
    draw(node)
    ch=children(node)
    for child in reversed(ch):
        stack.append(child)

turtle.done()
