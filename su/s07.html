Ⅰ. 분할정복·병합 정렬 학습자료

성취 목표
전체 문제를 작은 부분 문제로 나누고, 각 부분 문제의 해결 결과를 결합하여 전체 문제를 해결하는 분할정복 알고리즘을 설계하며, 병합 정렬의 실행 과정과 시간 복잡도를 분석한다.

1. 분할정복의 핵심 구조

분할→ 정복→ 결합

분할

하나의 큰 목록을 크기가 비슷한 두 부분으로 나눈다.

정복

나눈 부분 목록을 같은 방법으로 재귀적으로 정렬한다.

결합

정렬된 두 부분 목록을 비교하면서 하나의 정렬 목록으로 합친다.

2. 문제 상황

정렬되지 않은 목록 [38, 27, 43, 3, 9, 82, 10]을 병합 정렬을 이용하여 오름차순으로 정렬한다. 

[38, 27, 43, 3, 9, 82, 10]
├─ [38, 27, 43]
│  ├─ [38]
│  └─ [27, 43]
│     ├─ [27]
│     └─ [43]
└─ [3, 9, 82, 10]
   ├─ [3, 9]
   │  ├─ [3]
   │  └─ [9]
   └─ [82, 10]
      ├─ [82]
      └─ [10]

3. 병합 과정

단계왼쪽 목록오른쪽 목록결합 결과
1[27][43][27, 43]
2[38][27, 43][27, 38, 43]
3[3][9][3, 9]
4[82][10][10, 82]
5[3, 9][10, 82][3, 9, 10, 82]
6[27, 38, 43][3, 9, 10, 82][3, 9, 10, 27, 38, 43, 82]

4. 수행 과제

  1. 병합 정렬의 분할·정복·결합 과정을 설명한다.
  2. 두 정렬 목록을 합치는 merge() 함수를 작성한다.
  3. 재귀적으로 목록을 나누고 정렬하는 merge_sort()를 작성한다.
  4. 분할과 결합 과정을 들여쓰기로 출력한다.
  5. 빈 목록, 한 원소, 중복값, 정렬 목록, 역순 목록을 시험한다.
  6. 병합 정렬의 시간 복잡도와 공간 복잡도를 분석한다.

6. 정답 포함 전체 코드

from typing import TypeVar

T = TypeVar("T")


def merge(left: list[T], right: list[T]) -> list[T]:
    """정렬된 두 목록을 하나의 정렬된 목록으로 결합한다."""
    result: list[T] = []
    i = 0
    j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    # 한쪽 목록에 남은 자료를 결과에 이어 붙인다.
    result.extend(left[i:])
    result.extend(right[j:])

    return result


def merge_sort(values: list[T], depth: int = 0) -> list[T]:
    """
    분할정복 방식으로 목록을 정렬한다.
    depth는 분할과 결합 과정을 보기 좋게 출력하기 위한 값이다.
    """
    indent = "  " * depth
    print(f"{indent}분할: {values}")

    # 원소가 0개 또는 1개이면 이미 정렬된 상태이다.
    if len(values) <= 1:
        return values.copy()

    # 1. 분할: 목록을 두 부분으로 나눈다.
    middle = len(values) // 2
    left = values[:middle]
    right = values[middle:]

    # 2. 정복: 두 부분을 각각 재귀적으로 정렬한다.
    left_sorted = merge_sort(left, depth + 1)
    right_sorted = merge_sort(right, depth + 1)

    # 3. 결합: 정렬된 두 부분을 하나로 합친다.
    merged = merge(left_sorted, right_sorted)

    print(
        f"{indent}결합: "
        f"{left_sorted} + {right_sorted} -> {merged}"
    )

    return merged


def run_test(values: list[T]) -> None:
    """원본과 정렬 결과를 출력하고 정확성을 검증한다."""
    print("\n" + "=" * 64)
    print("시험 자료:", values)

    sorted_values = merge_sort(values)

    print("원본:", values)
    print("정렬:", sorted_values)

    assert sorted_values == sorted(values)
    print("검증 결과: 표준 sorted() 결과와 일치합니다.")


data = [38, 27, 43, 3, 9, 82, 10]
run_test(data)

# 추가 시험
run_test([])
run_test([5])
run_test([4, 2, 4, 1, 2])
run_test([1, 2, 3, 4, 5])
run_test([5, 4, 3, 2, 1])

8. 알고리즘 의사코드

병합 정렬(values)
    values의 길이가 1 이하이면
        values의 복사본을 반환한다.

    가운데 위치를 구한다.
    왼쪽 부분과 오른쪽 부분으로 나눈다.

    왼쪽 부분을 병합 정렬한다.
    오른쪽 부분을 병합 정렬한다.

    정렬된 왼쪽과 오른쪽을 병합하여 반환한다.


병합(left, right)
    빈 결과 목록을 만든다.
    왼쪽과 오른쪽의 현재 위치를 0으로 둔다.

    두 목록에 비교할 자료가 남아 있는 동안
        더 작은 값을 결과에 추가한다.
        해당 목록의 위치를 한 칸 이동한다.

    왼쪽 또는 오른쪽에 남은 자료를 결과에 추가한다.
    결과를 반환한다.

9. 효율성 분석

항목분석
분할 깊이목록을 절반씩 나누므로 약 log₂n 단계
단계별 결합량각 깊이에서 전체 n개 원소를 비교·이동
시간 복잡도O(n log n)
공간 복잡도병합을 위한 추가 목록과 재귀 호출을 포함하여 O(n)
안정 정렬같은 값에서 왼쪽 자료를 먼저 선택하면 기존 순서를 유지할 수 있음

10. 수행평가 문항

1. 병합 정렬에서 분할, 정복, 결합이 각각 무엇을 의미하는지 설명하시오.
2. len(values) <= 1을 종료 조건으로 사용하는 이유를 설명하시오.
3. merge() 함수가 두 정렬 목록을 하나로 합치는 원리를 설명하시오.
4. 병합 정렬의 시간 복잡도가 O(n log n)인 이유를 설명하시오.
5. 병합 정렬이 추가 메모리를 사용하는 이유와 장단점을 설명하시오.

11. 예시 정답

문항 1 정답
분할은 목록을 두 부분으로 나누는 과정이다. 정복은 나눈 각 부분을 재귀적으로 정렬하는 과정이다. 결합은 정렬된 두 부분 목록을 비교하여 하나의 정렬 목록으로 합치는 과정이다.
문항 2 정답
원소가 없거나 하나뿐인 목록은 이미 정렬된 상태이다. 따라서 더 나눌 필요가 없으며 재귀 호출을 끝내는 기본 사례가 된다.
문항 3 정답
두 목록의 현재 원소를 비교하여 더 작은 값을 결과 목록에 넣고, 선택한 목록의 위치를 한 칸 이동한다. 한쪽 목록이 끝나면 다른 목록의 남은 자료를 모두 붙인다.
문항 4 정답
목록을 절반씩 나누므로 재귀 깊이는 약 log₂n이다. 각 깊이에서 전체 원소 n개를 병합하는 작업이 필요하므로 전체 시간 복잡도는 O(n log n)이 된다.
문항 5 정답
정렬된 두 부분을 합치기 위해 새로운 결과 목록이 필요하고, 재귀 호출 정보도 저장해야 하므로 추가 메모리를 사용한다. 대신 입력 배열의 상태와 관계없이 안정적으로 O(n log n)의 성능을 제공하고 안정 정렬이 가능하다는 장점이 있다.

13. 종합 정리

분할: 큰 문제를 더 작은 두 부분 문제로 나눈다.

정복: 각 부분을 같은 방법으로 해결한다.

결합: 두 정렬 결과를 하나의 정렬 목록으로 합친다.

효율성: 병합 정렬은 입력 상태와 관계없이 O(n log n)의 시간 복잡도를 가지지만 O(n)의 추가 공간이 필요하다.
