응시 안내

01 · 빈칸 완성한 줄 또는 지정된 블록을 작성합니다. 전체 코드가 아니라 빈칸에 들어갈 코드만 입력합니다.
02 · 출력 추적서로 다른 출력 보기 5개 중 정확히 하나를 선택합니다. 공백과 자료형도 확인하세요.
03 · 코드 분석보기 5개 중 옳은 설명 3개를 선택합니다. 3개가 모두 맞아야 정답입니다.
  • Python 3 기준입니다. 그래픽·GUI 문항은 명령 기록 또는 함수 테스트로 변형했으며 문항별 변경점을 표시했습니다.
  • 문항당 1점, 총 30점입니다. 원본 실습의 1·2점 배점 대신 이 HTML에서는 모든 문항에 같은 배점을 적용합니다. 100점 환산은 정답 수÷30×100입니다.
  • 서답형은 등록 답안과 표현 정규화가 일치하면 자동 정답, 나머지는 교사 검토 대기입니다. 의미가 같은 코드도 미등록 표현이면 대기할 수 있으며, 오답으로 단정하지 않습니다.
  • 제출 전에는 답을 변경할 수 있습니다. 제출 후 정답·보기별 해설이 공개되며 답안은 잠깁니다. 서답형 검토 완료 후 최종 점수 TXT를 저장하세요.
  • 모든 처리는 이 브라우저 안에서 이루어집니다. 서버 전송·자동 영구저장은 없습니다. 새로고침·창 닫기 전에는 답안을 제출하고 TXT를 저장하세요.
평가 범위와 운영 주의
제공된 성취기준 30개 항목은 중복을 제외하면 18종입니다. 문항은 원본 수행평가의 순서(8+9+13)를 유지하고 실제 평가 내용에 맞게 재매핑했습니다. 원본에 없는 DP·큐·안전한 입력 검증은 확장 코드로 명시했습니다. 소프트웨어 설계·협업·윤리 기준은 일부 요소만 평가하며, A~E 종합 성취수준을 자동 판정하지 않습니다.
이 파일에는 채점용 정답이 포함됩니다. 소스 열람이나 교사 검토 버튼을 막는 보안 장치가 없으므로 고부담 시험용 보안 시스템이 아닌 학습·교사 감독 평가 자료입니다.
